## 一、游戏概要

### 1-1. 游戏人数

- 本游戏原则上由 **2 名玩家**进行对战
- 目前综合规则不支持其他人数

### 1-2. 游戏的胜负

#### 败北条件（2 种）

| # | 条件 | 说明 |
|---|------|------|
| 1 | 生命 0 + 领袖受伤 | 生命卡牌为 0 张时，领袖受到伤害 |
| 2 | 卡组抽空 | 卡组的卡牌张数变为 0 张 |

**规则处理时点**：若任一玩家满足败北条件，在下一个规则处理时点该玩家败北（参考 §九）。

#### 认输

- 玩家可在游戏中**任何时点**宣言认输
- 认输立刻败北，游戏结束
- 认输**不受任何卡牌影响**，无法被置换效果阻止

#### 特殊胜利/败北

- 某些卡牌效果可直接导致玩家胜利或败北

### 1-3. 游戏的大原则

| 原则 | 说明 |
|------|------|
| **文本优先** | 卡牌文本与综合规则矛盾时，以卡牌文本为优先 |
| **尽可能执行** | 无法完全执行时，在可能范围内执行；完全无法执行则不做 |
| **禁止优先** | "可以做"与"禁止做"同时存在时，以禁止为优先 |
| **同时选择** | 多名玩家同时选择时，回合玩家先选 |
| **数量选择** | 除非特别指定，必须选 0 以上的整数；若标注"最多～"，可选 0 |
| **数值下限** | 效果修正的数值通常不低于 1（力量可变为负数、费用计算中可为负但显示为 0） |
| **文本顺序** | 卡牌效果按文本从前往后顺序执行 |
| **状态冲突** | 同时被要求"转为休息"和"转为活跃"时，以**转为休息**为优先 |
| **同时行动** | 同时指示双方行动时，回合玩家先执行 |

## 二、卡牌信息

### 2-1. 卡牌种类（5 种）

| 种类 | 说明 | 放置区域 | 常量 |
|------|------|----------|------|
| **领袖卡牌** | 每方 1 张，对战核心 | 领袖区（固定） | `Leader` |
| **角色卡牌** | 登场战斗，可攻击/防御 | 角色区 | `Character` |
| **事件卡牌** | 一次性效果，使用后进废弃区 | 废弃区 | `Event` |
| **舞台卡牌** | 持续效果 | 舞台区 | `Stage` |
| **咚!!卡牌** | 费用资源 | 费用区 / 咚!!卡组 | `Don` |

### 2-2. 卡牌编号

- 同一编号在卡组中**最多 4 张**

### 2-3. 颜色（6 种）

| 颜色 | 六边形位置 |
|------|-----------|
| 红色 | 右上方 |
| 绿色 | 右方 |
| 蓝色 | 右下方 |
| 紫色 | 左下方 |
| 黑色 | 左方 |
| 黄色 | 左上方 |

- 卡牌可拥有**多个颜色**（多色卡牌）
- 多色卡牌视为拥有所有颜色的卡牌来处理
- 构筑卡组时只能放入**包含领袖颜色**的卡牌

> **注意**: 项目卡牌数据中使用 `炎/水/雷/风/心` 等颜色名，与官方中文规则的颜色命名体系不同。项目实现时请以数据文件中的实际值（`color` 字段）为准。

### 2-4. 特征（keywords）

- 1 张卡牌可拥有多个特征，用 `/` 隔开（如 `超新星/草帽一伙`）
- 文本中用 `《》` 指定特征，用 `<>` 指定特征的一部分

### 2-5. 属性（6 种）

| 属性 | 说明 |
|------|------|
| 斩 | 剑士/刀系 |
| 打 | 拳法/打击系 |
| 射 | 远程/射击系 |
| 特 | 特殊能力 |
| 知 | 智力/策略系 |
| ? | 未知/通用 |

- 只有**领袖卡牌和角色卡牌**拥有属性
- 卡牌可拥有多个属性

### 2-6. 力量（Power）

- 只有领袖卡牌和角色卡牌拥有力量值
- 力量值可被效果修改，**可能变为负数**
- 力量负数的卡牌不会自动进废弃区

### 2-7. 费用（Cost）

- 从手牌打出卡牌时需要支付的**咚!!数量**
- 只有角色卡牌、事件卡牌、舞台卡牌拥有费用
- 费用可被效果修正，计算中可暂时为负，**不足 1 时视为 0**

### 2-8. 卡牌文本

- 领袖/角色/舞台卡牌的效果只在对应区域中有效
- `()` 内为注释，在游戏中没有实际意义
- **按文本从前往后顺序执行**效果

### 2-9. 生命（Life）

- 只有领袖卡牌拥有生命值
- 对战开始时，从卡组最上方抽取与生命相同张数的卡牌背面朝上置于生命区
- 原本卡组最上方的卡牌置于生命区**最下方**

### 2-10. （图标）反击

- 只有角色卡牌拥有的在反击步骤中可使用的能力
- 使用后该角色卡牌**置入废弃区**，增加对应数值的力量

### 2-11. 【触发】（Trigger）

- 受到伤害时，可**代替加入手牌**而发动该效果
- `【触发】` 是卡牌文本的一部分

### 2-12. 稀有度

7 种稀有度：`L`（领袖）、`SR`（超级稀有）、`R`（稀有）、`UC`（非普通）、`C`（普通）、`SEC`（秘密）、`P`（特别）

### 2-13. 对战无关信息

版权标识、稀有度、环境标识、插图、画师名——在对战中不具有意义。

## 三、游戏的区域

### 3-1. 区域总览

```
┌──────────────────────────────────────────────────────────────┐
│                        对方区域                                │
│  [对方领袖区]  [对方舞台区]  [对方角色区: 1][2][3][4][5]      │
│  [对方生命区]  [对方卡组]    [对方手牌(牌背)]   [对方费用区]   │
│  [对方废弃区]  [对方咚!!卡组]                                  │
├──────────────────────────────────────────────────────────────┤
│                       中线信息栏                               │
│  [己方费用显示]  [当前回合&阶段]  [对方费用显示]                │
├──────────────────────────────────────────────────────────────┤
│                        己方区域                                │
│  [己方废弃区]  [己方咚!!卡组]                                  │
│  [己方费用区]  [己方手牌]    [己方卡组]    [己方生命区]         │
│  [己方领袖区]  [己方舞台区]  [己方角色区: 1][2][3][4][5]      │
└──────────────────────────────────────────────────────────────┘
```

### 3-2. 九大区域详解

| # | 区域 | 公开性 | 说明 |
|---|------|--------|------|
| 1 | **卡组** | 非公开 | 背面朝上重叠放置，不可查看/变更顺序 |
| 2 | **咚!!卡组** | 公开 | 10 张咚!!卡牌的堆叠区，可查看内容和顺序 |
| 3 | **手牌** | 非公开 | 自己可查看和排序，对手不可查看 |
| 4 | **废弃区** | 公开 | 被 KO 的卡牌、发动后的事件卡牌 |
| 5 | **领袖区** | 公开 | 领袖卡牌固定位置，不会因效果从此区移动 |
| 6 | **角色区** | 公开 | 最多 **5 张**角色卡牌 |
| 7 | **舞台区** | 公开 | 最多 **1 张**舞台卡牌 |
| 8 | **费用区** | 公开 | 咚!!卡牌堆放处，活跃/休息状态 |
| 9 | **生命区** | 非公开 | 背面朝上，通常不可查看内容和顺序 |

### 3-3. 区域重要规则

- "领袖区 + 角色区 + 舞台区 + 费用区"统称为"**场上**"
- 区域中卡牌张数对所有玩家**公开**
- 卡牌移动到其他区域后，视为**新区域中的新卡牌**，原效果不再适用
- 咚!!卡牌移动区域后，此前所有适用效果消失
- 多张卡牌同时放置时，由持有者决定顺序

### 3-4. 角色区满员处理

当角色区已有 5 张卡时需登场新角色：
1. 公开想登场的卡牌
2. 将已有 1 张角色卡牌**置入其持有者废弃区**（此处理为规则处理，不触发任何效果）
3. 新角色卡牌登场

### 3-5. 舞台区满员处理

当舞台区已有 1 张卡时需登场新舞台卡同理：先废弃旧卡，再登场新卡。

## 四、游戏的基础用语

### 4-1. 卡牌表示形式

| 状态 | 描述 |
|------|------|
| **活跃状态**（Active / 立置） | 纵向放置，可攻击/可使用效果 |
| **休息状态**（Rest / 横置） | 横向放置，已使用过 |

- 赋予中的咚!!卡牌**既不属于活跃也不属于休息状态**

### 4-2. 抽卡（Draw）

- 从卡组最上方取 1 张，不公开，加入手牌
- "抽 N 张" = 重复 N 次"抽 1 张"
- "抽取最多 N 张" = 可以选择在任意次后停止

### 4-3. 伤害处理

领袖受到伤害时的步骤：
1. 受到 1 点伤害 → 将生命区**最上方**的 1 张卡牌加入手牌
2. 若该卡牌有 `【触发】` → 可选择公开并发动效果**以代替加入手牌**
3. 受到 N 点伤害 → 重复 N 次上述步骤

### 4-4. 打出卡牌

- 支付费用并从手牌中发动/登场卡牌
- "无法打出" = 不能支付费用登场或发动

### 4-5. 赋予咚!!卡牌

- 将费用区中 1 张活跃状态的咚!!卡牌重叠在领袖或角色卡牌下方
- 我方回合中，每赋予 1 张咚!!卡牌，该卡牌**力量 +1000**
- 被赋予的卡牌移动区域 → 咚!!卡牌以**休息状态**放回费用区

### 4-6. 关键概念

| 概念 | 说明 |
|------|------|
| **"原本的"** | 指卡牌上记载的数字/文本 |
| **"场合"** | 前文无法解决 → 后文也不能解决 |
| **"之后"** | 前文无法解决 → 后文仍可解决 |
| **"离开"** | 卡牌从放置区域移动到其他区域 |
| **"将力量变为0"** | 减去与当前力量相同数值的效果 |

## 五、游戏的准备

### 5-1. 卡组构筑规则

| 规则 | 官方规定 | 当前项目实现 |
|------|---------|-------------|
| 卡组总张数 | **50 张** | **40 张** |
| 同名卡上限 | 4 张 | 4 张 |
| 领袖卡牌 | 1 张 | 1 张 |
| 咚!!卡组 | 10 张 | — |
| 颜色限制 | 只能放入含领袖颜色的卡牌 | 未强制 |

> **重要**: 项目当前使用 40 张卡组。后续是否需要更新为官方 50 张规则需要确认。本文档后续描述以官方 50 张规则为准。

### 5-2. 对战前准备流程

```
步骤 1: 双方出示卡组（符合构筑规则）
步骤 2: 各自充分切洗卡组，背面朝上叠放至卡组区
步骤 3: 领袖卡牌正面朝上放置至领袖区
步骤 4: 通过猜拳等方式决定由谁选择先攻/后攻
步骤 5: 被选中的玩家选择先攻或后攻
      → 处理"游戏开始时"效果（先由该玩家处理，再由另一方处理）
      → 若对卡组进行了操作，需重新切洗
步骤 6: 各玩家抽 5 张手牌
      → 从先攻玩家开始，各自有 1 次重抽机会（全部放回→切洗→重新抽 5 张）
步骤 7: 各玩家从卡组最上方抽取与领袖生命相同张数的卡牌
      → 背面朝上置于生命区
      → 原卡组最上方卡牌在生命区最下方
步骤 8: 先攻玩家成为回合玩家，游戏开始
```

### 5-3. 先攻/后攻差异

| 差异 | 先攻方 | 后攻方 |
|------|--------|--------|
| 第一回合抽卡阶段 | **不抽卡** | 抽 1 张 |
| 第一回合咚!!阶段 | +1 咚 | +2 咚 |
| 后续回合 | 正常 | 正常 |
| 第一回合攻击 | **不能攻击** | 可以攻击 |

## 六、游戏的进行（回合流程）

### 6-1. 五阶段结构

```
┌─────────────────────────────────────────────────────────┐
│ ① 重置阶段（Reset Phase）                                │
│   ├── "直到回合开始时为止"的效果失效                       │
│   ├── 发动"回合开始时"效果                                │
│   ├── 赋予领袖/角色的咚!!卡牌以休息状态放回费用区           │
│   └── 领袖区、角色区、舞台区、费用区中的所有休息卡牌→活跃   │
├─────────────────────────────────────────────────────────┤
│ ② 抽卡阶段（Draw Phase）                                  │
│   └── 回合玩家抽 1 张卡牌（先攻第一回合不抽）              │
├─────────────────────────────────────────────────────────┤
│ ③ 咚!!阶段（Don!! Phase）                                 │
│   ├── 从咚!!卡组将 2 张咚!!卡牌以活跃状态置于费用区         │
│   └── 先攻第一回合仅 +1 张；咚!!卡组不够则取全部           │
├─────────────────────────────────────────────────────────┤
│ ④ 主要阶段（Main Phase）★ 核心操作阶段                    │
│   ├── 发动"主要阶段开始时"效果                             │
│   ├── 可反复进行的操作（任意顺序）：                       │
│   │   ├── 打出卡牌（支付费用登场/发动）                    │
│   │   ├── 发动卡牌效果（【启动主要】【主要】）              │
│   │   ├── 赋予咚!!卡牌（费用区→领袖/角色下方）              │
│   │   └── 战斗（攻击宣言，进入战斗序列）                   │
│   └── 宣言结束主要阶段 → 进入结束阶段                      │
├─────────────────────────────────────────────────────────┤
│ ⑤ 结束阶段（End Phase）                                   │
│   ├── 发动【我方的回合结束时】自动效果（仅1次）             │
│   ├── 发动【对方的回合结束时】自动效果（仅1次）             │
│   ├── 处理"本回合结束时"/"结束阶段结束时为止"的持续效果     │
│   ├── 处理"本回合中"期限效果失效                           │
│   └── 本回合结束 → 对方成为回合玩家 → 进入下一回合①        │
└─────────────────────────────────────────────────────────┘
```

### 6-2. 主要阶段详细操作

#### 6-2-1. 打出卡牌

| 操作 | 流程 |
|------|------|
| **登场角色卡牌** | ① 公开卡牌 → ② 选择与费用相同张数的活跃咚!!→转为休息 → ③ 卡牌登场至角色区（活跃状态） |
| **登场舞台卡牌** | ① 公开卡牌 → ② 选择与费用相同张数的活跃咚!!→转为休息 → ③ 卡牌登场至舞台区（活跃状态） |
| **发动事件卡牌** | ① 公开卡牌 → ② 选择与费用相同张数的活跃咚!!→转为休息 → ③ 卡牌置入废弃区 → ④ 发动效果 |

- 新登场的角色卡牌在其登场的回合中**不能攻击**（除非有【速攻】）

#### 6-2-2. 发动卡牌效果

- 回合玩家可发动描述为 `【主要】` 或 `【启动主要】` 的效果
- 战斗以外的主要阶段中进行

#### 6-2-3. 赋予咚!!卡牌

- 将费用区中活跃状态的咚!!卡牌放置于我方领袖或角色卡牌下方
- 我方回合中，每有 1 张赋予的咚!!，该卡牌**力量 +1000**
- 可多次执行
- 被赋予的卡牌移动区域 → 咚!!卡牌以休息状态放回费用区

## 七、卡牌的攻击和战斗

### 7-1. 攻击的基本规则

- 仅回合玩家的主要阶段可攻击
- **第 1 回合不能战斗**
- 将**活跃状态**的领袖/角色卡牌转为**休息状态**来攻击
- 攻击对象：对方**领袖卡牌**或对方角色区中**处于休息状态的 1 张角色卡牌**

> **关键规则**: 只能攻击对方**横置（休息）**状态的角色卡牌。无法攻击处于活跃（竖置）状态的角色卡牌。

### 7-2. 战斗五阶段

```
┌─────────────────────────────────────────────────────────┐
│ ① 攻击·步骤（Attack Step）                               │
│   攻击方：                                                │
│   ① 将 1 张活跃状态的领袖/角色转为休息 → 攻击宣言         │
│   ② 选择攻击目标：对方领袖 或 对方休息状态的 1 张角色     │
│   ③ 发动【攻击时】/【对方的攻击时】/被攻击时效果          │
│   ④ 若攻击方/目标在此步骤结束时移动区域 → 直接到⑤         │
├─────────────────────────────────────────────────────────┤
│ ② 阻挡·步骤（Block Step）                                │
│   防守方（被攻击方）：                                     │
│   ① 可在该次战斗中仅限 1 次发动【阻挡者】效果              │
│   ② 发动【阻挡者】→ 攻击对象变更为阻挡者角色卡            │
│   ③ 发动【阻挡时】效果                                    │
│   ④ 若攻击方/目标在此步骤结束时移动区域 → 直接到⑤         │
├─────────────────────────────────────────────────────────┤
│ ③ 反击·步骤（Counter Step）                              │
│   防守方可反复执行：                                       │
│   ① 发动（图标）反击：将手牌中有反击值的角色卡置入废弃区   │
│      → 被攻击的领袖/角色力量 + 反击值                      │
│   ② 发动【反击】事件卡牌：支付费用→置入废弃区→发动效果    │
│   ③ 若攻击方/目标在此步骤结束时移动区域 → 直接到⑤         │
├─────────────────────────────────────────────────────────┤
│ ④ 伤害·步骤（Damage Step）                               │
│   威力比较：                                              │
│    攻击力量 >= 被攻击力量 → 战斗胜利                       │
│      ├── 目标是领袖 → 给予 1 点伤害                        │
│      │   ├── 对方生命为 0 → 攻击方获胜                     │
│      │   ├── 对方生命 >= 1 → 对方将生命区最上方卡牌+手牌    │
│      │   │   └── 有【触发】→ 可选择公开并发动              │
│      │   └── 若【双重攻击】→ 伤害为 2，重复 2 次            │
│      └── 目标是角色 → KO 该角色卡牌                         │
│    攻击力量 < 被攻击力量 → 战斗失败，无事发生               │
├─────────────────────────────────────────────────────────┤
│ ⑤ 战斗结束（Battle End）                                  │
│   ① 发动"战斗结束时"/"进行战斗的场合"效果                  │
│   ② "本次战斗中"期限的效果失效                             │
│   ③ 返回主要阶段                                          │
└─────────────────────────────────────────────────────────┘
```

### 7-3. 战斗关键点

- 攻击卡必须横置（活跃→休息），攻击宣言后不能同回合再次攻击
- 防御方使用【阻挡者】后，原攻击目标被替换为阻挡者
- 反击步骤中，防守方可使用多张反击卡
- 【触发】在生命区卡牌加入手牌时中断伤害处理，可选择发动

## 八、效果的发动和解决

### 8-1. 效果的四大分类

| 类型 | 说明 | 卡牌描述示例 |
|------|------|-------------|
| **自动效果** | 每次发生指定事件时必定自动发动 1 次 | `【登场时】【攻击时】【阻挡时】【KO时】【我方的回合结束时】【对方的回合结束时】` |
| **启动效果** | 回合玩家在主要阶段中可宣言发动 | `【启动主要】【主要】` |
| **永续效果** | 在有效期间内持续生效 | `【咚!!×1】【我方的回合中】【对方的回合中】` |
| **置换效果** | 将某个处理"改为..."或"以...代替" | `"改为......""......以代替"` |

#### 自动效果重要规则

- 每次满足事件时自动发动 1 次（除非有特别指示）
- 可以有发动费用或条件
- 若在发动前卡牌已移动到其他区域，则**无法发动**（除【KO时】为特例）

#### 永续效果重要规则

- 符合条件时必定持续生效
- 存在"在规则上"描述的永续效果，即使在非公开区域也有效
- 多个永续效果相互作用时，按[回合玩家→非回合玩家→重新检查]顺序循环处理

#### 置换效果重要规则

- 可选择不适用
- 多人同时有置换时：效果发生源优先→回合玩家→非回合玩家
- 同一置换效果在同一次处理中**只能适用 1 次**
- 效果处理中途也可适用

### 8-2. 效果的有效和无效

- 效果被无效的卡牌**不视为**"原本没有效果的卡牌"
- 已发动且正在解决中的自动/启动效果**不会因其他效果变为无效**
- 被无效的卡牌获得新效果 → 新效果通常不会无效

### 8-3. 发动费用和条件

#### 发动费用

- `:` 前的行动即为**发动费用**
- 记号 `①` = 选择 1 张活跃状态咚!!转为休息
- 记号 `咚!!-○` = 从领袖区/角色区/费用区选择○张咚!!放回咚!!卡组
- 无法支付部分费用 → 全部无法支付，且不能处理 `:` 后的效果

#### 条件

- `【咚!!×○】` = 赋予此卡牌 ○ 张或更多咚!!卡牌即符合条件
- `【我方的回合中】` / `【对方的回合中】` = 对应回合即符合条件
- `～的场合` = 不符合则不解决后续效果

### 8-4. 效果的发动和解决流程

```
① 确认发动条件符合
② 指定要发动的效果（若为手牌中效果则公开该卡牌）
③ 若有发动费用则支付全部费用
④ 实际发动效果
⑤ 进行效果的解决
```

### 8-5. 解决顺序

- 双方效果同时满足发动时点 → **回合玩家先解决**
- 回合玩家解决效果后 → 若对方有效果满足时点则对方解决 → 回合玩家再解决其他效果
- 伤害处理中满足发动时点 → 全部伤害处理完后才发动（除【触发】可中断伤害处理）
- 因发动卡牌/效果导致满足时点 → 当前效果解决完后才发动

## 九、规则处理

### 9-1. 基本

- 规则处理是游戏中自动执行的强制处理
- 即使正在进行其他行动，**也会在发生时点立刻解决**

### 9-2. 败北判定

在规则处理开始时点，满足以下任一条件的玩家**败北**：

| 条件 | 说明 |
|------|------|
| 生命 0 + 领袖受伤 | 生命为 0 张时领袖受到伤害 |
| 卡组 0 张 | 卡组卡牌张数为 0 |

## 十、关键词效果和关键词

### 10-1. 关键词效果

| 关键词效果 | 说明 |
|-----------|------|
| **【速攻】** | 角色卡牌在登场的回合中也可以攻击 |
| **【双重攻击】** | 对领袖生命造成的伤害为 **2** 而非 1 |
| **【流放】**（Banish） | 对领袖生命造成伤害时，生命卡牌放置于**废弃区**（不进手牌），不发动【触发】 |
| **【阻挡者】**（Blocker） | 在阻挡步骤中将活跃状态的此卡转为休息 → 攻击对象变更为此卡 |
| **【触发】**（Trigger） | 从生命区确认时，可**公开并发动**效果以代替加入手牌 |
| **【速攻：角色】** | 登场的回合中也可以攻击对方角色卡牌 |
| **【不可阻挡】** | 此卡牌的攻击中，对方**不能发动【阻挡者】效果** |

### 10-2. 关键词

| 关键词 | 说明 |
|--------|------|
| **KO** | 战斗中败北或卡牌效果导致角色卡牌进入废弃区 |
| **【启动主要】** | 可在战斗以外的主要阶段中发动 |
| **【主要】** | 事件卡牌专有，仅在战斗以外主要阶段可打出 |
| **【反击】** | 事件卡牌专有，仅在对方反击步骤可打出 |
| **【攻击时】** | 我方攻击步骤攻击宣言时发动 |
| **【登场时】** | 卡牌登场时发动 |
| **【KO时】** | 从场上被 KO 时在场发动，之后移到废弃区解决效果 |
| **【阻挡时】** | 发动【阻挡者】效果的阻挡步骤中发动 |
| **【对方的攻击时】** | 对方攻击步骤攻击宣言时发动（在对方【攻击时】效果后） |
| **【我方的回合结束时】** | 我方结束阶段发动（每回合仅限 1 次） |
| **【对方的回合结束时】** | 对方结束阶段发动（每回合仅限 1 次） |
| **【咚!!×○】** | 条件：赋予此卡牌 ○ 张或更多咚!! |
| **咚!!-○** | 费用：选择 ○ 张咚!!放回咚!!卡组 |
| **【我方的回合中】** | 条件：在我方回合中 |
| **【对方的回合中】** | 条件：在对方回合中 |
| **【每回合1次】** | 每回合仅限发动并解决 1 次 |
| **丢弃** | 从手牌选择卡牌放置于废弃区 |

### 10-3. KO 详细规则

| 规则 | 说明 |
|------|------|
| 什么算 KO | 只有"将～KO"的效果或因战斗结果才会触发 KO 时效果 |
| 什么不算 KO | 通过其他方法将角色卡牌置入废弃区（如满员规则处理）不视为 KO |
| KO 时效果特例 | KO 时效果在场上发动，但卡牌移动到废弃区后才解决效果 |

## 十一、其它规则

### 11-1. 永久循环

若出现可永久持续进行的循环行动：

| 情况 | 处理 |
|------|------|
| 双方都无法停止 | 对战以**平局**结束 |
| 仅一方能停止 | 该方宣言循环次数 → 执行该次数后停止 → 状态完全相同时不能再选 |
| 双方都能停止 | 回合玩家先宣言次数 → 对方宣言次数 → 取**较少次数** → 执行后停止 |

### 11-2. 卡牌的公开

- 从非公开区域移动特定条件的卡牌到另一非公开区域时，**必须公开**该卡牌
- 非公开区域卡牌因效果/费用被公开后，在解决后恢复为非公开

### 11-3. 查看非公开区域

- 仅限效果的持有者可以确认
- 正在查看时不能移动卡牌
- 查看后若无特别指示，放回原位

### 11-4. 重抽机制补充

- 每位玩家**仅 1 次**重抽机会
- 将全部手牌放回卡组 → 切洗 → 重新抽 5 张
- 从先攻玩家开始依次选择
