# 启动流程

## 推荐启动顺序

1. 先启动**服务端**（让 WebSocket 在 8080 端口就绪）
2. 再启动**客户端**（连接到服务端）

---

## 启动服务端（WebSocket 服务器）

服务端是 C# .NET 10 程序，位于 `服务端WebSocket/` 目录。

**开发调试：**
```powershell
cd "D:\Self\GrandUMI\服务端WebSocket"
dotnet run
```

**指定端口（默认 8080）：**
```powershell
dotnet run -- 9090
```

启动成功后显示：
```
╔══════════════════════════════════════╗
║    GrandUMI WebSocket 服务器          ║
║    ws://localhost:8080/ws/            ║
║    按 Ctrl+C 停止                     ║
╚══════════════════════════════════════╝
```

按 `Ctrl+C` 停止服务器。

> **Windows 权限问题**：若需监听非 localhost 地址，须以管理员身份运行，或提前注册 URL ACL：
> ```bat
> netsh http add urlacl url=http://+:8080/ws/ user=Everyone
> ```

---

## 启动客户端（Web 前端）

客户端是 Next.js 应用，位于 `opcgpro-web/` 目录。

**开发模式（带热重载）：**
```powershell
cd "D:\Self\GrandUMI\opcgpro-web"
npm run dev
```

启动后访问：`http://localhost:3000`

**其他命令：**
```powershell
npm run build   # 构建生产版本
npm run start   # 启动生产版本（需先 build）
```
