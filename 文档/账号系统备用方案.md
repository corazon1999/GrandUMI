# 账号系统备用方案

## 背景

当前 WebSocket 服务器（`服务端WebSocket/WebSocketBridge.cs`）使用存根登录：任意非空账号密码均视为成功。
原始游戏服务器（`39.107.122.119:1003`）有真实账户数据库，暂无直接访问。

## 三层数据说明

| 层级 | 位置 | 作用 |
|------|------|------|
| 客户端缓存 | `OPCGPro/Assets/StreamingAssets/Account.json` | 记住上次登录账号，仅用于自动填充输入框 |
| 原始服务器 | `39.107.122.119:1003` 数据库 | 真实账户验证（已有，暂不对接） |
| 我们的 WS 服务器 | 内存（无持久化） | 当前为存根，需要时替换 |

## 实现方案（待启用）

**方式：JSON 文件持久化，无需数据库**

在 `服务端WebSocket/` 目录新增：

```
服务端WebSocket/
├── accounts.json          # 账户数据文件（自动生成）
└── AccountManager.cs      # 账户管理类
```

**`AccountManager.cs` 功能：**
- `Register(id, password, name)` — 注册，密码用 SHA256 哈希后存储
- `Verify(id, password, out name)` — 验证账号密码
- 数据格式：

```json
[
  { "Id": "666666", "PasswordHash": "sha256(666666)", "Name": "船长" },
  { "Id": "test",   "PasswordHash": "sha256(123456)", "Name": "测试账号" }
]
```

**接入点（WebSocketBridge.cs `OnLogin` 方法）：**

```csharp
// 当前存根（替换这两行）
bool ok   = account.Length > 0 && password.Length > 0;
var  name = ok ? account : "";

// 替换为：
bool ok = AccountManager.Verify(account, password, out string name);
```

**`OnAddAccount` 同理：**

```csharp
// 替换 TODO 处
AccountManager.Register(id, password, name);
```

## 触发条件

满足以下任一条件时启用：
- 需要多人使用不同账号
- 需要账号与卡组数据绑定（当前卡组存 localStorage，与账号无关）
- 正式上线前
