# OPCGPro 项目架构文档

> **项目名称**: YGOGrandUMI（游戏大UMI）  
> **游戏引擎**: Unity 2021.3.26f1c1 (LTS)  
> **编程语言**: C# 8.0 / .NET 4.7.1  
> **平台支持**: Windows / Android / iOS  
> **文档日期**: 2026-05-12

---

## 一、项目概述

OPCGPro 是一款以《海贼王》为题材的多人实时网络卡牌游戏，基于 Unity 2021 LTS 开发。游戏实现了完整的卡牌对战系统，包含多人在线对战、观战、回放、卡组编辑等功能。

### 基本信息

| 项目 | 值 |
|------|-----|
| 产品名称 | YGOGrandUMI |
| 公司名称 | D の一味 |
| 版本号 | 0.998.262.302 |
| Unity 版本 | 2021.3.26f1c1 (LTS) |
| 默认分辨率 | 1920×1080（横屏） |
| 目标帧率 | 60 FPS |
| 颜色空间 | Linear |

```

  ↓

  ↓                   Protobuf 序列化
```

## 四、核心模块详解

### 4.1 游戏管理系统 (Game/Manager)

| 类名 | 职责 |
|------|------|
| `GameManager.cs` | 主管理器，维护游戏全局状态（模式、双方资源、流程） |
| `BattleManager.cs` | 战斗流程管理（攻击/防御/反击/伤害阶段） |
| `EventManager.cs` | 游戏内消息显示与事件调度 |
| `PlaybackManager.cs` | 游戏录制与回放 |
| `AudioManager.cs` | 背景音乐与音效管理 |
| `CardObjPool.cs` | 卡牌对象池（复用优化） |
| `RequestManager.cs` | 向服务器发送游戏操作请求 |
| `AcceptManager.cs` | 接收并分发服务器响应 |

**GameManager 核心状态**：

```csharp
GameMod        // Player / Observer / Playback
Cost           // 费用区（Active, Max, Zone）
Hand           // 手牌（HandCards, CanChoose）
Field          // 场地（CharacterCards, StageCard）
Deck           // 卡组（MainDeck, RemainCount）
Life           // 生命值（Current, Max）
Stage          // 舞台卡（StageEffect）
Leader         // 领航卡（CharacterCard, SpecialAbility）
IsStart        // 是否先攻
CurrentTurn    // 是否当前回合
TurnCount      // 回合数
HaveExtraturn  // 是否有额外回合
```

### 4.3 能力/效果系统 (Game/Ability)

**处理流程**：

```
EffectBase.cs（基础抽象类）
    ↓
EffectHandler.cs（效果处理器）
    ↓
EffectByNum/（具体效果实现，按编号索引）
    ├── BE/    Basic Effect 系列
    ├── CR01–CR15/  Card Raise 系列
    ├── EB01–EB04/  Event Base 系列
    └── P/, D/ 其他系列
```

**效果触发时机（EffectTime）**：

| 时机 | 说明 |
|------|------|
| Main | 主阶段 |
| Counter | 反击阶段 |
| Trigger | 触发效果 |
| Attack / BeAttack | 攻击 / 被攻击时 |
| Block | 防御时 |
| Appear | 出场时 |
| OnKO | 被 K.O. 时 |
| TurnStart / TurnEnd | 回合开始/结束 |
| Damage / BeDamage | 造成/承受伤害时 |

### 4.4 网络通信系统 (Client/Net)

**核心组件**：

| 类名 | 职责 |
|------|------|
| `NetManager.cs` | Socket 管理（连接/断连/心跳/消息队列） |
| `GameProtocol.cs` | 游戏中消息的编解码与分发 |
| `HomeProtocol.cs` | 大厅消息的编解码与分发 |
| `ByteArray.cs` | 字节数组工具（读写封装） |
| `AES.cs` | AES 对称加密实现 |
| `MsgBase.cs` | 消息基类 |

**协议枚举（ProtocolEnum，共 24 种）**：

```
MsgSecret(1)      密钥交换
MsgPing(2)        心跳
MsgCreateRoom(3)  创建房间
MsgGetRoomList(4) 获取房间列表
MsgEnterRoom(7)   进入房间
MsgPrepare(9)     准备就绪
MsgGameStart(10)  游戏开始
MsgShuffle(11)    洗牌
MsgChatMsg(14)    聊天消息
MsgTransmit(15)   游戏操作传输
MsgLogin(18)      登录
MsgAddAccount(20) 注册账户
...
```

**安全机制**：

- 握手阶段：公钥 `"GrandUMIServer"` 完成密钥交换
- 通信阶段：AES 动态密钥加密
- 序列化：protobuf-net
- 心跳间隔：30 秒

### 4.6 事件系统 (Event)

**EventCenter.cs** 实现了观察者模式的中央事件总线，支持 0–5 个泛型参数的回调：

```csharp
// 订阅
EventCenter.Instance.AddListener<T1, T2>(MyEventType.XX, callback);

// 发布
EventCenter.Instance.Broadcast(MyEventType.XX, arg1, arg2);

// 取消订阅
EventCenter.Instance.RemoveListener(MyEventType.XX, callback);
```

## 六、战斗流程

```
回合开始
    ↓
抽卡阶段（Draw Phase）
    ↓
主阶段（Main Phase）
    ↓ 出牌 / 使用效果 / 攻击宣言
攻击阶段（Attack Phase）
    ↓
  攻击方选择攻击卡和目标
    ↓
防御阶段（Block Phase）
    ↓
  防守方选择防御卡（或不防）
    ↓
反击阶段（Counter Phase）
    ↓
  双方使用反击效果
    ↓
伤害计算（Damage Phase）
    ↓
  Final Damage = 攻击威力 + Buff - 防御威力 - Buff
    ↓
（可选）额外回合（Extra Turn）
    ↓
回合结束（Turn End）
```
