## #19 OP11-054「抽3放2」面板无卡图

**现象**：OP11-054 奈美登场（领袖多色时抽3、再选2张手牌放回卡组顶/底），那个"选手牌放回"的面板里卡牌只显示蓝色「CARD」占位，看不到抽到/要放回什么。

**根因**：前端 `PromptOverlay.tsx` 的 `findCardById` 只能从「场上卡(fieldCards)+领袖」反查卡号；对于卡组/手牌等**不下发身份**的隐藏区候选，约定由后端在 `ChooseCards` 的 `extra.choiceCards` 里携带 `{id, number}`，前端才能映射卡号、加载卡图（大量卡已遵守，如 LookTopReveal、OP05_082、OP05_007）。而 `服务端WebSocket/Effects/Scripted/OP11_054_Nami.cs:41` 调 `ChooseCards("OwnHand", …)` 选手牌时**漏传了 extra**，候选 id 是手牌 GUID，前端查不到 → 占位。
（前端无法单独修：`store` 里 `my` 只有 `handCardNumbers`(卡号数组)，没有手牌的 id，映射不出来；必须后端按约定下发。）

**修复**（`OP11_054_Nami.cs`，循环内每次按当前手牌构造）：
```csharp
var handExtra = new Dictionary<string, object?>
{
    ["choiceCards"] = hand.Select(c => new { id = c.Id.ToString(), number = c.Info.Number }).ToList(),
};
var pick = await ctx.Prompts.ChooseCards(ctx.OwnerIndex, "OwnHand",
    "选择 1 张手牌放回卡组（共 2 张）",
    hand.Select(c => c.Id.ToString()).ToList(), 1, 1, handExtra);
```

**同类隐患（未被反馈，记录待查）**：其它选手牌但没传 extra 的脚本面板同样会无卡图，例如 `OP05_058_StopTramplingLife.cs:57`（丢手牌至5张）、`OP05_041_Sakazuki.cs:38`（丢1手牌）。若后续有反馈，照此补 `choiceCards` 即可。

## #38/#39/#40 在线玩家按钮与聊天发送键重叠

**现象**：大厅(Lobby)里「查看在线玩家」徽标固定在右下角 `absolute bottom-3 right-4`，与聊天室右下的「发送」按钮位置打架。三条反馈同一问题，玩家建议把徽标做成可拖动。

**修复**（`opcgpro-web/src/components/home/MainPanel.tsx` `OnlineCountBadge`）：改为可拖动徽标——
- 指针事件 `onPointerDown/Move/Up` + `setPointerCapture` 实现拖拽；移动超过 4px 阈值才算拖动，否则当作点击（仍打开在线玩家列表），避免误触。
- 拖动用 `position: fixed`（相对视口）+ 边界约束（不会拖出屏幕）。
- 落点写入 `localStorage`(`grandumi_online_badge_pos`)，刷新后恢复。
- 默认位置仍是右下 `bottom-3 right-4`，`z-10`→`z-30` 提到聊天面板之上；`touch-none select-none` 适配移动端拖动。
