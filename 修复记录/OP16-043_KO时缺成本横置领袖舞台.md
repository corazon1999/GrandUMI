# OP16-043 — 【KO时】缺可选成本（横置《德莱斯罗兹》领袖/舞台）

## 现象
- KO 撒谎布触发【KO时】，只弹出「选对方费用≤5角色回手」，**没有先提示选择成本**（横置我方《德莱斯罗兹》领袖或舞台）。

## 卡面
- 【阻挡者】
- 【KO时】可以将我方1张拥有《德莱斯罗兹》特征的领袖或舞台转为休息状态：将对方最多1张费用不高于5的角色放回其持有者的手牌。

## 根因
- 原实现是**纯 DSL**（`Definitions/OP16.json`）。DSL 的 `triggers` 节**没有激活成本（cost）通道**，所以只实现了收益（直接 `Choose`+`BounceToHand`），成本被整段跳过。DSL 注释自承「可选成本无法表达，仅实现收益」。

## 修复
**后端**：新建 `Effects/Scripted/OP16_043_Usopp.cs`，`HandlesTrigger(OnKO)`：
1. 收益候选 = 对方 `CurrentCostOf ≤ 5` 角色，无目标则不发动。
2. 成本候选 = 我方**活跃**且 `Info.HasKeyword("德莱斯罗兹")` 的**领袖 / 舞台**。
3. 「可以」=可选：成本 `ChooseCards(min 0)`，放弃则不发动；选了则 `RestCard` 横置。
4. 收益：`BounceToHand(state, oppIdx, tgt)` 回其持有者手牌。
- 脚本按 trigger 优先覆盖 DSL；原 OP16-043 DSL 占位保留但不执行，`_matcher` 已标注被脚本接管。未改 effectTags（已含 OnKO，原 DSL 能触发已证明）。

**前端（通用修复）**：`components/game/PromptOverlay.tsx` 的 `findCardById` / `fieldStateById` 原本只认领袖 + `fieldCards`，**舞台不在 `fieldCards`**（是 `stageId/stageNumber/stageTapped` 扁平字段），导致舞台候选「能点选但卡图空白」。补上 `id === my/opp.stageId` 的反查（卡图 + 横置态）。

## 波及卡牌
- 「KO时 + 横置我方领袖/舞台成本」同款：未发现其它，无需联动改。
- **前端舞台点选修复是通用的**：此后任何让玩家在 prompt 里点选舞台的效果都能正常显示卡图（不止 OP16-043）。

## 预防
- DSL `triggers` 节不支持激活成本（cost）。凡「可以付出X：收益」型的【KO时】/【登场时】等触发效果，**必须转 C# 脚本**，不能用 triggers DSL 近似（会丢成本）。
- prompt 候选可含领袖 / 角色 / 舞台 / 咚四类；新写「选舞台」效果前，确认 `PromptOverlay` 反查已支持（现已支持）。
