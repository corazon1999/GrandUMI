# 条件阻挡者误成无条件常驻 — 批量修复 60 张

## 根因
`ActionValidator.HasKeyword`（`Game/Validation/ActionValidator.cs:105-110`）三条路径**有序短路**：
```csharp
if (Array.IndexOf(c.Info.Abilities, kw) >= 0) return true;   // 107 静态词条 → 无条件
if (c.GainedKeywords.Any(k => k.Keyword == kw)) return true; // 108 临时赋予(GiveKeyword)
return s.HasContinuousKeyword(c, kw);                         // 109 条件持续(ContinuousEffect.GrantKeyword)
```
卡面是「满足条件/临时才获得阻挡者」的卡，被解析器把效果文里的【阻挡者】误写进静态 `abilities`，于是 107 行无条件命中，永远当阻挡者，**完全无视卡面条件**。

## 分类与处理（共 60 张）

### 第一档：删 abilities 即可 = 44 张
阻挡者已由别处正确提供（条件持续脚本 / 临时 GiveKeyword / 赋予他人 / 事件卡），静态 abilities 纯属误标，删除后由正确路径接管：
- **A 类自身已有 ContinuousEffect 条件持续（32）**：EB02-012/033、EB03-018/044、EB04-056/057、OP02-031、OP04-005、OP05-062/086、OP06-010/054/072/113、OP07-029/030、OP10-053/108、OP11-057/065/096、OP12-066、OP13-112、OP14-011、OP15-024/068、OP16-113、P-004/105/113、ST27-004、ST28-002（后者在 ST28_Passives.cs）。
- **临时/触发型已用 GiveKeyword 实现（9）**：EB04-061、OP04-059、OP04-071、OP13-106、OP09-068、OP15-060 等（走 GainedKeywords 路径，与静态 abilities 独立）。
- **赋予他人型（自身误标，4）**：OP02-074(给"蓝猩")、OP12-012(给"巴奇以外")、OP07-024(给鱼人族)、OP10-099(领航给超新星)。
- **事件卡误扫（2）**：OP12-016("对方无法发动阻挡者")、OP15-055。

## 关键坑（本批踩到/规避）
1. **自动扫描按文件名前缀会漏集中脚本**：初版用前缀 `ST25_002_` 找脚本，漏掉集中写在 `ST25_Passives.cs` 的 ST25-002/005、`ST28_Passives.cs` 的 ST28-002——它们靠类的 `CardNumber` 注册，与文件名无关。OP16-073(DSL)同样被误判"未实现"。**核查覆盖必须 grep CardNumber 字符串，不能靠文件名。** 因此 16 张里有 3 张其实早已实现，只需删 abilities。
2. **脚本 OnEnterField 会覆盖 DSL 登场效果**：`EffectRuntime.Resolve` 脚本命中即 return 不退 DSL（108-116）。OP15-053/087 另有 DSL【登场时】效果，新建脚本须在注册 ContinuousEffect 后 `await DslInterpreter.TryResolve(ctx)`（范式见 ST27_004_SanjuanWolf.cs），否则登场效果丢失。
3. **登场 Resolve 不门控 effectTags**：打出角色走 `GameEngine.cs:407` 直接 `Resolve(OnEnterField)`，不查 effectTags（注释 205 明说为了让"靠登场注册持续效果"的卡注册）。故新建/改脚本用 OnEnterField 注册 ContinuousEffect **无需补 effectTags**。但 watcher 类触发（OnMyTurnEnd 等）经 CollectListeners 门控 effectTags——OP16-073 的 OnMyTurnEnd 段就靠 effectTags 含 OnMyTurnEnd 才触发（本已含）。
4. **GrantKeyword 只认 Predicate 不认 Scope**：`GameState.HasContinuousKeyword:185` 仅 `eff.GrantKeyword==kw && eff.Predicate(...)`，不应用 Scope。Predicate 必须写 `card.Id == selfId`，否则全场角色都获得阻挡者（参见记忆 continuous-effect-scope-ignored）。

## 已知偏差/仍未实现（超出本批范围）
- OP13-089/091 的 `LeaveGuard="effect"` 引擎粒度为"任意效果离场"，略宽于卡面"对方的效果"（自己效果也无法使其离场）。影响极小，待引擎支持"按发起方"粒度时精修。
- OP12-053 的【每回合1次】"因对方效果将要离场时弃手牌不离场"替代效果无触发钩子，仍未实现。
- OP15-060 前半"咚≤6不离场+力量+2000"被动、OP15-011 的【KO时】等同卡其他条款按各自 DSL/现状，未在本批改动。
