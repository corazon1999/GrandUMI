# OP16-036 — 缺【攻击时】实现（原本力量变为对方领袖力量）

## 现象
- OP16-036 Mr.2·盆·岁末(本萨姆) 打出、攻击时，卡面【攻击时】效果没有发生。

## 卡面（两段效果）
- 【登场时】将对方最多1张费用不高于4的角色转为休息状态。
- 【攻击时】本回合中，此角色原本的力量变为与对方领袖力量相同。

## 根因
- 该卡原本是**纯 DSL** 实现（`Effects/Definitions/OP16.json`），但 DSL 条目里**只有 `OnEnterField` 一个 trigger**，登场休息部分正常；**完全没有 `OnAttackDeclare` 的处理**。
- 卡数据 `effectTags` 其实**已含 `["OnEnterField","OnAttackDeclare"]`**（与 OP16-055 一致），所以引擎攻击时会派发此卡（`HasEffectForTrigger` 依据 EffectTags）。但派发后走到 `EffectRuntime.Resolve`：无脚本 → 退回 `DslInterpreter.TryResolve` → DSL 里没有 OnAttackDeclare 段 → 空过。
- 即：**会派发，但没有任何 handler 接管** → 攻击时无效果。

## 修复
- 新建 `Effects/Scripted/OP16_036_Bentham.cs`，`HandlesTrigger` 仅返回 `OnAttackDeclare`：
  ```csharp
  ctx.Source.OriginalPowerOverride = ctx.State.CurrentPowerOf(oppIdx, oppLeader);
  ```
- 引擎分发按 **trigger 粒度**「脚本优先、否则退回 DSL」（`EffectRuntime.Resolve`：`scripted != null && scripted.HandlesTrigger(trigger)` 才走脚本）。本脚本不处理 OnEnterField，故**登场休息仍走原 DSL**，无双重触发。
- **未改** OP16.json、**未改** effectTags（已含 OnAttackDeclare）。
- 几乎照搬已正常工作的 OP16-055（同名同效），唯一区别：OP16-055 有【咚×1】门槛，OP16-036 无门槛。
- `OriginalPowerOverride` 本回合性：回合末由 `TurnEngine` 清除；本卡被赋予的咚加成仍叠加其上，符合「原本力量变为X」语义。

## 波及卡牌
- 「【攻击时】原本力量变为对方领袖力量」同款仅 OP16-055，已正确实现，无需改。
- 未对全卡池做「effectTags 标了 trigger 但无 handler」的横扫审计（超本次范围）；如需可单独排查。

## 预防
- **effectTags 标了某触发，就必须有对应 handler**（DSL trigger 段或脚本 HandlesTrigger），否则该时机会派发后空过、效果静默丢失。
- 一张卡可「DSL + 脚本」混用：脚本按 trigger 接管局部时机，未接管的退回 DSL，互不冲突。
