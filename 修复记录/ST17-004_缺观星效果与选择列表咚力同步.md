# ST17-004 波尔·汉库珂 — 缺观星效果 & 选择列表未同步真实咚/攻击力

## 现象
1. ST17-004 登场后只发动「贴休息咚」，没有【登场时】前置的「观星」（确认卡组顶 3 张自选顺序放顶/底）。
2. 选择贴咚目标时，选择列表里的候选卡显示的是基础卡面（如 6000），看不到目标当前已贴的咚数与实际攻击力。

## 卡面原文
【阻挡者】【登场时】确认我方卡组最上方的 3 张卡牌，将其自选顺序排列并放置到卡组最上方或最下方。
之后，赋予我方 1 张拥有《王下七武海》特征的领袖或角色最多 1 张休息状态的咚!!。

## 根因
- 旧实现是 DSL（`Effects/Definitions/ST17.json`），_note 注明「原文前置 scry 顶 3 张无 scry op 已略去」——只做了第 2 段贴咚，缺第 1 段观星。
- 选择类 prompt 的前端组件 `PromptOverlay.tsx` 渲染候选卡时，只把 `choiceCards` 的 `{id, number}` 反查成基础 `CardData` 传给 `CardItem`，没有传场上真实的 `attachedDon`/`powerCurrent`，故 DON 徽标与当前攻击力恒为基础值。

## 修复
1. **新建脚本** `服务端WebSocket/Effects/Scripted/ST17_004_BoaHancock.cs`：完整实现两段效果。
   - 观星：`AtomicOps.ReorderTopK`（同 EB03-023 嘉雅 / EB02-023 克洛克达尔），自选顺序 + ChooseOption 放顶/底。
   - 贴咚：`HasKeyword("王下七武海")` 过滤领袖+角色，`AtomicOps.AttachDonFromCost(..., DonState.Rest)`。
   - 脚本优先于 DSL（EffectRuntime 命中脚本即 return）。
2. **删除 DSL 冗余** `服务端WebSocket/Effects/Definitions/ST17.json` 的 ST17-004 整块（避免歧义）。
3. **前端通用修复** `opcgpro-web/src/components/game/PromptOverlay.tsx`：新增 `fieldStateById(id)`，对场上卡（含领袖）返回 `{attachedDonCount, powerBuff}`，其中 `powerBuff = powerCurrent - 基础power - attachedDon*1000`，使 `CardItem` 的 displayPower 等于服务端权威当前攻击力；渲染选择项时传给 `<CardItem>`。所有选择类 prompt 同享此同步（卡组/手牌等非场上候选回退基础卡面）。

## 验证
- 后端 `dotnet build`：0 错误 0 警告。
- `ST17.json` JSON 合法。
- 前端 `npx tsc --noEmit`：通过。

## 关联
- 同类「顶 N 张重排放顶/底」：EB03-023 嘉雅、EB02-023 克洛克达尔。
- 选择列表渲染：所有走 `choiceCards` 的效果均受益于本次前端同步。

# 追加修复（同卡续）：无休息咚时不应消耗活跃咚

## 现象
ST17-004 用 GM「召唤到场」(不付费) 后场上无休息咚，贴咚选择确认目标时会**回退吃掉 1 张活跃咚**贴上，用户感知为「无法正常结算」。

## 根因
共用原语 `AtomicOps.AttachDonFromCost` 在请求 `DonState.Rest` 但费用区无休息咚时，会**回退取活跃咚**补足（旧约定，OP14-105 等卡注释明确依赖）。真实对局里「赋予休息咚」均在支付费用横置咚之后结算，必有休息咚、回退不触发；仅 GM 不付费召唤等边缘场景才暴露。

## 决策
经与用户确认：**全局改为「赋予休息咚」只用休息咚，无休息咚则不赋予（选择后无事发生）**。此为房规，略偏离官方规则（官方允许取活跃咚以休息态赋予），但真实对局无差异，仅边缘场景行为变化。

## 修复（全局）
1. `服务端WebSocket/Effects/AtomicOps.cs` — `AttachDonFromCost` 移除 Rest→Active 回退，严格按 `fromState` 取咚；更新注释。
2. `Effects/Scripted/ST17_004_BoaHancock.cs` — 贴咚前加守卫：费用区无休息咚则直接 `return` 跳过该选择（不弹无意义提示）。
3. `Effects/Scripted/OP13_006_Uppslap.cs`、`OP13_119_Ace.cs` — 删除各自的手动 Rest→Active 回退，统一只用休息咚；更新注释。
4. `Effects/Scripted/OP14_105_GorgonSisters.cs` — 更新「依赖回退」的注释。
5. 其余 50+ 张走 `AttachDonFromCost(...Rest)` 的 DSL/脚本卡自动继承新行为（共用原语）。
   - `DonState.Active` 路径（give-a-DON / 给对方活跃咚等）不受影响。
   - OP16-021（Active 优先、Rest 兜底）语义不变，保留。
