## #85 OP15-040 维奥拉 —— 检索退化成直接抽牌

**原文**：【登场时】确认我方卡组最上方的3张卡牌，公开其中最多1张拥有《德莱斯罗兹》特征的卡牌并加入手牌。之后，将剩余的卡牌自选顺序放回卡组最下方。
**根因**：DSL 是占位 `{op:Draw,n:1}`（_doc 明确注「精确实现待做」），完全没实现检索 → 玩家看到的就是"直接抽1"。
**修复**：替换为 `LookTopReveal`（仿已验证的 ST22-002 写法）：
```json
{ "op": "LookTopReveal", "count": 3, "max": 1, "restTo": "bottom",
  "match": { "keywordContains": "德莱斯罗兹" } }
```
`keywordContains`=特征包含（区别于精确 keyword），match 键名已对照 DslInterpreter.cs BuildMatchPredicate 确认合法。

## #86 OP15-019 防护罩 蛮牛突进 —— 事件主要漏抽1

**原文**：【主要】抽取1张卡牌，直到下个对方的结束阶段结束时为止，我方领袖力量+1000。【触发】本回合中，对方最多1张角色力量-4000。
**根因**：main.then 只有 `AddPowerThisTurn(selfLeader,+1000)`，**漏了抽1** → 玩家反馈"抽一张没发动"。
**修复**：main.then 加力前插入 `{op:Draw,n:1}`。
**遗留(未扩大改动)**：领袖+1000 原文是"直到下个对方结束阶段"，当前用 `AddPowerThisTurn`(本回合)简化，时长略短；#86 只诉求抽牌，未动此处。
