# 2026-06-17 对战页手机/iOS/夸克横屏适配「稀碎」修复

日期：2026-06-17
来源：QQ 群反馈 #9（手机端横屏适配稀碎）、#11（iOS 几乎无法横屏，适配夸克浏览器）

## 问题
手机横屏进入 `/game` 对战页，画面"稀碎"：偏移 / 留异常黑边 / 被浏览器工具栏盖住；iOS Safari、夸克浏览器尤甚，旋转后常需手动晃一下才恢复。

## 根因
对战页用固定设计画布 1280×720 + `transform: scale()` 等比缩放居中（scale-to-fit）。两处移动端缺陷：
1. 外层根容器用 `h-screen`(100vh)。iOS/夸克横屏时地址栏占位让 `100vh` 大于真实可视高度 → 居中盒比可视区高，画布偏出 / 被工具栏盖。
2. `useStageScale` 用 `window.innerHeight` 即时读数计算缩放。iOS/夸克在 `orientationchange` 触发瞬间返回旋转前的旧尺寸 → 旋到横屏后用竖屏尺寸算出错误 scale，画面碎掉，要手动 resize 才正。
3. 未使用 `window.visualViewport`（移动端工具栏伸缩时真实可视尺寸的唯一可靠来源）。

## 修复
- `opcgpro-web/src/hooks/useStageScale.ts`：测量优先用 `window.visualViewport`（回退 `innerWidth/innerHeight`）；新增监听 `visualViewport` 的 `resize`；`orientationchange` 后做 立即 + 双 `requestAnimationFrame` + 250ms 兜底 三次重测，躲开 iOS 旋转旧尺寸。
- `opcgpro-web/src/app/game/page.tsx`：对战页根容器 `h-screen w-screen` → `h-dvh w-dvw`（Tailwind v4 原生动态视口高度，居中盒=真实可视区，不被工具栏盖）。

竖屏提示（layout.tsx「请将设备横屏使用」）保留不动。桌面端不受影响。

## 验证
前端 `tsc --noEmit` 0 错误；一键部署 `build=0` 上线；用户真机实测 **iOS Safari + 夸克浏览器横屏均通过**。

## 备注
若后续 game/page.tsx 重构（如改走 GameBoard 组件），需确保根容器仍用 `h-dvh`、缩放仍走 `useStageScale`，否则本修复会回退。
