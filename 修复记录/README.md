# GrandUMI 卡牌修复记录

本文件夹记录**每一次卡牌问题的修复**，用于：
1. **找 bug 时优先查阅**：遇到卡牌效果异常，先在本文件夹搜索是否为已出现过的同类问题。
2. **修一处、查全部**：每修好一张卡，必须排查所有**语义相似的卡**是否需要一起修改，并把波及到的卡一并记录。

## 约定（每次修卡后执行）
- 每条修复新建一个文件：`OPxx-yyy_简述.md`（按主修卡号命名；一次波及多张时主卡号 + 在正文列出全部）。
- 修好一张后，**搜索语义相似卡**（相同触发/相同机制/相同文本模式）并逐一检查；同款问题一并修复并记入本条记录的"波及卡牌"。
- 在下方"索引"追加一行。

## 记录格式（复制下面模板）
```
---
卡号: OPxx-yyy （及波及的其它卡号）
日期: YYYY-MM-DD
现象: 玩家看到的表现 / 复现路径
根因: 真正原因（代码位置）
修复: 改了什么（文件/做法）
波及卡牌: 排查语义相似卡的结论（哪些一起改了、哪些已确认无碍）
预防: 以后如何避免 / 同类排查要点
```
