## 2.1 持续效果「全场误加成」（Scope 被忽略，作用对象须写进 Predicate）
引擎 `GameState.ContinuousPowerBonus` 只看 `Predicate`、完全忽略 `Scope`（见 OP15-050 正确参照）。
- **OP07-087 巴斯卡比尔**：Predicate 补 `card.Id == selfId`，否则条件成立时全场（含领袖/对方）都 +3000。
- **OP10-001 斯摩格**：过滤原只写在 `Scope.Filter`（被忽略），Predicate 仅判回合 → 对方回合时全场每卡 +1000。Predicate 补 `sideIdx==owner && card.Info.Kind != Leader && (HasKeyword 海军 || 班克禁区)`。

## 2.2 用字/数据不匹配致条件永不命中
- **OP13-016 戈普**：领袖名判断写「波特**卡**斯·D·艾斯」，卡库统一用「波特**夹**斯」→ 艾斯领袖下登场检索永不触发。已全文「卡」→「夹」（含注释）。
- **OP10-032 达斯琪**（绿/风不匹配）：已由本日「全栈颜色标准化」自愈（脚本"绿"↔数据"绿"），见 `修复记录\2026-06-18_全栈颜色标准化…md`。

## 2.3 目标错位（未定义 prompt 落兜底返回对方角色）
- 解释器 `BuildCandidates` 缺 `OwnTrashCharacterCostLe1`（OP14-084 第二段）、`Le8`（OP14-093）→ 落 `default => opp.Characters` 从**对方**场登场/回收。
- 修复：① 补全 `OwnTrashCharacterCostLe1/Le2/Le8`；② 给 OP14-084(两个 Choose)/093(一个 Choose) 加 `filter:{keyword:"巴洛克工作室"}`（Choose 已支持 filter，复用 BuildMatchPredicate）；③ **default 兜底由 `opp.Characters` 改为告警+返回空候选**（`UnknownPromptFallback`），绝不再静默返回对方场。
- 全量比对确认：除这两个外，全库 DSL 再无 prompt 落兜底。
- 注：「巴洛克工作室」与「原巴洛克工作室」是独立特征，卡面《巴洛克工作室》→ 精确匹配前者，不含"原"。

## 2.5 「放置废弃区」成本误用 KO
