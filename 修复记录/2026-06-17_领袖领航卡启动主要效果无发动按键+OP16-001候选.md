现象: 以领航/领袖卡（type=领航，引擎归为 CardKind.Leader）作为来源的【启动主要】效果，游戏内没有「发动效果」按钮，玩家无法发动。战国(OP16-060)、艾斯(OP16-001)等领航卡受影响。

## 根因（唯一拦路点在前端）

后端其实**早已完整支持领袖卡发动 ActivatedMain**：
- `服务端WebSocket/Game/ActionValidator.cs:114` `CanUseEffect` 校验 `me.Leader.Id == sourceId || me.Characters... || me.StageCard...` —— 含领袖。
- `服务端WebSocket/Game/GameEngine.cs:767` `HandleUseEffect` 查找 source 时 `me.Leader.Id == sourceId ? me.Leader : ...` —— 优先匹配领袖。
- `Effects/Dsl/DslInterpreter.cs:122` ActivatedMain 的 oncePerTurn / 费用(咚返还、转休息等) 对任意 source（含领袖）统一适用，无特殊限制。
- 战国 OP16-060 的脚本 `OP16_060_Sengoku.cs` 已完整实现启动主要效果。

**问题全在前端**：`opcgpro-web/src/components/game/GameActions.tsx:44-49` 计算选中卡卡号 `selectedNumber` 时，只判断了舞台卡(`my.stageId`)和角色卡(`my.fieldCards`)，**漏掉了领袖卡(`my.leaderId`)**。导致领袖/领航卡即便被选中、且 effectTags 含 "ActivatedMain"，`canActivate` 也永远为 false，不显示「发动效果」按钮。
（领袖卡点击可正常选中：`LeaderCard.tsx` handleClick 在 side==="my" 时 `setSelectedField(player.leaderId)`；`my.leaderId/leaderNumber` 字段在 net.ts:330-331 / gameStore.ts:45-46 均存在。）

## 修复

### 1. 前端通用修复（解决 #41 #44，及 #30 的「没按钮」）
`opcgpro-web/src/components/game/GameActions.tsx`，`selectedNumber` 增加领袖分支：
```ts
const selectedNumber =
  my && selectedFieldId !== null
    ? selectedFieldId === my.leaderId      // ← 新增：领袖/领航
      ? my.leaderNumber
      : selectedFieldId === my.stageId
        ? my.stageNumber
        : (my.fieldCards.find((c) => c.id === selectedFieldId)?.number ?? null)
    : null;
```
所有有 ActivatedMain 的领航/领袖卡从此选中后即显示发动按钮，点击发 `GameRequest.useEffect(leaderId, "main")`，后端已能处理。

### 2. OP16-001 艾斯脚本（贴原文「我方1张」含领袖自身）
`服务端WebSocket/Effects/Scripted/OP16_001_Ace.cs:20`，候选池从「仅角色」扩到「领袖+角色」（艾斯领袖 keyWords 含「白胡子海盗团」，原文「我方 1 张力量≥8000 的路飞 或 白胡子海盗团」未限定角色）：
```csharp
var pool = new List<CardInstance> { me.Leader };
pool.AddRange(me.Characters);
var candidates = pool.Where(c => c.Info.Power >= 8000 &&
    (c.MatchesName("蒙奇·D·路飞") || c.Info.HasKeyword("白胡子海盗团"))).ToList();
```
名称/keyword 判断保持原样（卡库实为「白胡子海盗团」，290 处一致；非反馈措辞「海贼团」）。

## 反馈 #32 重新定性（已挪出本批）

`OP11-041 奈美` 的 effectTags = `OnOppAttackDeclare / OnCharLeaveField / OnLifeLeaveField`，**没有 ActivatedMain**，即该领袖没有「主动发动」的效果。所以 #32「攻击对方领袖后无法发动领袖效果」**不是缺按键**，而是它的领袖效果「【我方回合】每回合1次 当生命牌离场且手牌≤7 时抽1」(OnLifeLeaveField 段) 在 `OP11_041_Nami.cs` **未实现**（脚本只做了「对方攻击时弃牌+2000」一段；引擎其实已在 `Game/LifeRevealManager.cs:84` 派发 OnLifeLeaveField）。**与 #27 同一根因，已挪到 D 批一起做**（需仔细处理：哪方生命牌、回合归属、手牌上限、每回合1次）。
