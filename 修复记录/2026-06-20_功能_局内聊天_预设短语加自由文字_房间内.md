# 2026-06-20 新功能：局内聊天（房间内，预设短语 + 自由文字）— 反馈 #134

反馈 #134「保皇说局内聊天没做，需要做」。原本只有**大厅全局聊天**（`MsgChatMsg` → `BroadcastAll` 发所有在线人，渲染于 `components/home/ChatPanel.tsx`），**对局内（/game）没有聊天**。本次新增房间内聊天，与大厅聊天完全独立。

## 设计（用户确认）
- 形式：**预设短语 + 自由文字** 两者都要
- 附加：**静音开关**（屏蔽对手）、**观战者可看可发**、**聊天历史栏**
- 聊天是瞬时消息，**不进对局状态/快照**，不影响回放/重连

## 服务端（服务端WebSocket/WebSocketBridge.cs）
- 新协议 `MsgGameChat`（区别于大厅 `MsgChatMsg`）：分发加 `case "MsgGameChat": OnGameChat`。
- `OnGameChat`：`GameRoomManager.GetRoomBySession` 找房间 → 发给 **本房间双方 + 全部观战者**（不是 BroadcastAll）。
- 防刷屏：`GameChatAt` 字典限频 **1.2s/条**；文字**长度上限 100**；空串忽略。CloseSession 清理该字典。
- 回包带 `text/code/fromSeat(0/1玩家,-1观战)/fromAccount/fromName(s.PlayerName??s.Account)/fromRole`。

## 协议 + 客户端
- `types/net.ts`：新增 `MsgGameChat` 接口 + 并入 AnyMsg 联合。
- `net/eventBus.ts`：新增 `gameChat` 事件。
- `net/GameProtocol.ts`：`case "MsgGameChat" → eventBus.emit("gameChat", ...)`。
- `net/GameRequest.ts`：`sendGameChat(text, code?)` → `NetManager.send({proto:"MsgGameChat", Text, Code})`（客户端也截断 100）。
- 新组件 `components/game/GameChatPanel.tsx`：
  - 固定屏幕左下角 💬 按钮（不随画布缩放，手机可用）；未读红点；关闭时对手消息冒泡 ~4s 自动淡出。
  - 展开面板：历史栏（最近50条）+ 8 条预设短语 chip + 自由文字输入（Enter 发送）+ 静音开关。
  - 静音：忽略他人消息（自己仍显示）；客户端发送冷却 1.3s。
  - "你/对手/对方名(观战)" 标签：按 `fromAccount === netStore.account` 判断是否自己。
- `components/game/GameBoard.tsx`：挂 `<GameChatPanel isPlayback={isPlayback} />`（回放模式内部自隐）。

## 预设短语（初始 8 条，可后续加）
你好 / 好牌！ / 谢谢 / 手下留情 / 该你了 / 认输吧 / GG / 网络卡了，稍等
