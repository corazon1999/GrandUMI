## #161 手牌一多就产生 UI 卡牌漂移、UI 乱动（HandArea 布局稳定性）

- **根因**：`<motion.div layout>` + 手牌容器 `justify-center` 的组合。
  - `layout` 会在**任何**重渲染时对比子元素前后位置并播放 spring 动画；
  - `justify-center` 在「卡片总宽 / 容器宽」奇偶不齐时算出 0.5px 级**亚像素居中偏移**；
  - 对局中 store 频繁更新（currentTurn / phase / isPending / selectedHandIndex 等）→ 频繁 re-render
    → `layout` 反复把亚像素偏移当成位移播放 → 持续微动。手牌越多、re-render 越频繁越明显。
  - 上轮把 `marginLeft` 取整，但居中偏移由浏览器 `justify-center` 实时算，取整管不到 → 仍漂。

- **修复**（纯前端，`HandArea.tsx`）：把横向排布从「flex 居中 + 负 marginLeft + `layout`」
  改为**整数像素绝对定位**：
  - 容器：`flex justify-center overflow-x-auto` → `relative h-full overflow-visible`；
  - 每卡：`position:absolute; left:0; bottom:0`，水平位置由 `xOf(i)=startX + i*step` **整数公式**算出，
    `motion.div` 用 `animate={{ x: xOf(i) }}`（transform 平移）到位，**去掉 `layout`**；
  - `step` 取整、`startX = round(max(PAD/2, (wrapW-totalW)/2))` 整数居中起点；
  - 进出动画拆为 per-value transition：`x` 即时 spring（抽/打牌平滑重排）、`y`/`opacity` 保留 `i*0.04` 错落入场。
  - 空手牌提示文字改 `absolute inset-0 flex center`（容器已无 flex 居中）。
- **效果**：位置完全由我们控制的整数像素决定 → 无亚像素居中、无 `layout` 反复测量 →
  手牌再多、re-render 再频繁都不漂；抽/打牌仍有平滑滑动与进出动画。
- **校验**：`npx tsc --noEmit` 通过（0 error）。
- **上线**：纯前端改动，跑 `deploy-hk.ps1` 一键热更即可（按 diff 只重建前端侧）。
  建议线上开局凑满多张手牌、对局中频繁操作复测确认漂移消除。
