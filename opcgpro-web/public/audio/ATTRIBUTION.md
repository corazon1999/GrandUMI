# GrandUMI 音效素材说明

本目录首版音效均来自 Kenney 发布的游戏音频素材包，许可为
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)。
CC0 允许在个人和商业项目中使用、修改与再分发，且不强制署名；本文件仍保留来源，方便后续审计。

## 官方素材包

- [Casino Audio](https://kenney.nl/assets/casino-audio)：卡牌放置、滑动、展开以及筹码碰撞音效。
- [Interface Sounds](https://kenney.nl/assets/interface-sounds)：确认、询问、错误、连接和消息提示音。
- [Impact Sounds](https://kenney.nl/assets/impact-sounds)：伤害冲击和角色 KO 音效。
- [Music Jingles](https://kenney.nl/assets/music-jingles)：胜利与失败短句。

作者：Kenney（https://kenney.nl/）
