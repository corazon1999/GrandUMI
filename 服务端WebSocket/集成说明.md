# WebSocketBridge 集成说明

## 文件清单

| 文件 | 作用 |
|------|------|
| `WebSocketBridge.cs` | WebSocket 网关主体（含所有协议处理器） |
| `WsSession.cs` | 会话状态对象 |

---

## 第一步：添加 NuGet 依赖

服务器项目需要安装 `Newtonsoft.Json`：

```
Install-Package Newtonsoft.Json
```

或在 `.csproj` 中手动添加：

```xml
<PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
```

---

## 第二步：将两个文件复制到服务器项目

把 `WebSocketBridge.cs` 和 `WsSession.cs` 放入服务器项目的任意目录（如 `Server/WebSocket/`）。

---

## 第三步：在服务器启动时调用

在现有服务器的 `Main()` 或启动方法末尾添加两行：

```csharp
// 在 TCP 服务器启动之后调用
WebSocketBridge.Start(port: 8080);
```

在服务器关闭时：

```csharp
WebSocketBridge.Stop();
```

### Windows 权限问题

在 Windows 上，`HttpListener` 监听非 localhost 地址需要管理员权限，或提前注册 URL ACL：

```bat
netsh http add urlacl url=http://+:8080/ws/ user=Everyone
```

---

## 第四步：连接现有游戏逻辑

`WebSocketBridge.cs` 中标有 `// TODO` 的位置是需要对接现有服务器代码的地方：

| TODO 位置 | 需要调用的现有逻辑 |
|-----------|------------------|
| `OnLogin` 验证部分 | `AccountDatabase.Verify(account, password, out name)` |
| `OnAddAccount` | `AccountDatabase.Create(id, password, name)` |
| `OnUpdatePs` | `AccountDatabase.UpdatePassword(account, newPs)` |
| `OnGetRoomList` | `RoomManager.GetAll()` |
| `OnCreateRoom` 房间号 | `RoomManager.Create(...)` |
| `OnEnterRoom` | `RoomManager.Enter(roomId, account)` |
| `OnQuitRoom` | `RoomManager.Quit(roomId, account)` |
| `OnGameStart` 先后手 | `RoomManager.DetermineFirst(roomId, account)` |

## 协议格式约定

### 客户端 → 服务器

```json
{ "proto": "MsgLogin", "account": "user123", "password": "pass" }
```

### 服务器 → 客户端

```json
{ "proto": "MsgLogin", "account": "user123", "name": "昵称", "result": true, "logStr": "登录成功" }
```

### 协议标识字段

`proto` 使用 `ProtocolEnum` 枚举的名字符串（如 `"MsgLogin"`），与 C# `MsgBase.EncodeName` 编码方式一致。

---

## 并发注意事项

- **WebSocket 不支持并发 SendAsync**：`WebSocketBridge.SendAsync` 目前未加锁，高并发下可能抛出异常
- 如果服务器并发量大，在 `WsSession` 中加一把 `SemaphoreSlim(1, 1)` 保护写操作：

```csharp
// WsSession.cs 增加
public SemaphoreSlim SendLock = new SemaphoreSlim(1, 1);

// WebSocketBridge.SendAsync 改为
await session.SendLock.WaitAsync();
try { await ws.SendAsync(...); }
finally { session.SendLock.Release(); }
```

## 测试验证

服务器启动后，在浏览器控制台测试：

```js
const ws = new WebSocket('ws://localhost:8080/ws/');
ws.onmessage = e => console.log(JSON.parse(e.data));
ws.onopen = () => ws.send(JSON.stringify({ proto: 'MsgSecret', vesion: '0.998' }));
// 预期：收到 { proto: "MsgSecret", result: true, ... }
```

## TCP 服务器兼容性

- 原 TCP 服务器（端口如 8888）完全保留，原客户端（Unity 版本）继续使用 TCP
- WebSocket 服务器在新端口（8080）独立运行，Web 客户端使用 WebSocket
- 两个服务器共用同一套账户数据库和游戏逻辑
