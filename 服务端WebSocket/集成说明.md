# GrandUMI 服务端集成说明

服务端由 ASP.NET Core Kestrel 同时提供 WebSocket 和运维 HTTP 端点，不再使用 `HttpListener`，也不需要 Windows URL ACL。

## 启动

```powershell
cd D:\Self\GrandUMI\服务端WebSocket
dotnet run -- 8080
```

监听地址固定为 `127.0.0.1`，由 Caddy、Nginx 或 Cloudflare Tunnel 暴露公网入口：

- WebSocket：`ws://127.0.0.1:8080/ws`
- 存活：`http://127.0.0.1:8080/live`
- 就绪：`http://127.0.0.1:8080/ready`
- 版本：`http://127.0.0.1:8080/version`
- Prometheus 指标：`http://127.0.0.1:8080/metrics`

## 客户端握手

```json
{
  "proto": "MsgSecret",
  "vesion": "0.998",
  "supportsStateDelta": true
}
```

声明 `supportsStateDelta` 的客户端可能收到 `MsgGameStateDelta`，必须校验 `baseTick` 并合并到本地基线；基线不匹配时发送 `MsgRequestState`。未声明的旧客户端始终收到完整 `MsgGameState`。

## 公开匹配队列

`MsgEnterMatch.queueKind` 决定匹配队列、牌组格式与房间快照来源，服务端不会让不同队列的玩家互相匹配：

| `queueKind` | 模式 | 牌组规则 | 房间 `matchKind` |
|---|---|---|---|
| `casualStandard` | 标准休闲 | 当前标准环境禁限卡表 | `CasualStandard` |
| `casual` | 狂野休闲（兼容旧客户端） | 放宽标准轮换限制，仍执行官网禁卡表 | `CasualWild` |
| `ranked` | 标准排位 | 当前标准环境禁限卡表 | `Ranked` |
| `rankedWild` | 狂野排位 | 放宽标准轮换限制，仍执行官网禁卡表 | `RankedWild` |

新客户端应显式发送 `queueKind`，默认使用 `casualStandard`。旧客户端省略字段或传入未知值时仍进入历史 `casual` 队列，但同样会由服务端拒绝官网完全禁用卡与禁用组合。标准与狂野的休闲、排位都不能使用这些禁卡；好友邀请与房间码对战允许使用。旧恢复快照中的 `Casual` 仍可读取。

### 公开 Leader 统计口径

Leader 总榜、对阵、起手、玩家详情、常用 Leader 和“最强使用者”只统计 `Matchmaking`、`Casual`、`CasualStandard`、`CasualWild`、`Ranked` 与 `RankedWild` 六种明确公开来源。`Friendly`、`RoomCode`、`Bot`、`UnknownHuman` 及未来未评审的新来源默认不计入公开统计；好友与房间码对局仍作为逐局事实保留，并继续计入管理中心的真人完成场次。

`leader-stats.db` 启动时会在 SQLite 立即事务内将 v1 事实重算为 v2 资格，并以 `exclude_reason=private_match` 标记历史好友/房间码对局；原始对局、合法公开战绩和起手事实不会被删除。迁移带数据库版本、逐行统计版本和持久触发器，可安全重启、并发初始化，并约束发布失败回滚后的旧程序写入。所有公开查询还会按来源白名单过滤，因此测试服先升级而正式只读库尚未迁移时也不会展示私下战数据。

## 关键环境变量

| 变量 | 默认值 | 作用 |
|---|---:|---|
| `GRANDUMI_MAX_CONNECTIONS` | 1000 | WebSocket 连接硬上限；生产值必须以压测结果为准 |
| `GRANDUMI_MAX_ROOMS` | 400 | 活跃房间硬上限；生产值必须以压测结果为准 |
| `GRANDUMI_PLAYER_DB` | `<DATA_DIR>/players.db` 或项目内 `PlayerData/grandumi.db` | 单独覆盖玩家资料与卡组数据库路径；同机的测试服与正式服可指向同一文件以共享卡组 |
| `GRANDUMI_DATA_DIR` | 项目数据目录 | 玩家库、排行榜、录像、对局日志和恢复日志根目录 |
| `GRANDUMI_ACCOUNT_DB` | 未设置 | 独立共享账号安全库路径；设置后不得由常规服务启动流程自动创建 |
| `GRANDUMI_ACCOUNT_DB_PREPARED_MARKER` | 未设置 | 独立共享账号库的受控迁移准备标记；正式服务必须同时看到非空数据库、此标记和有效迁移审计才能启动 |
| `GRANDUMI_ACCOUNT_DB_ACTIVATION_MARKER` | 未设置 | 测试服共享库激活标记；标记不存在时测试服继续使用本环境账号表，不得自行迁移正式数据 |
| `GRANDUMI_ACCOUNT_DB_ALLOW_LOCAL_FALLBACK` | `0` | 仅测试服可设为 `1`；允许激活标记不存在时回退本环境账号表，正式服不得设置 |
| `GRANDUMI_ONLINE_PLAYER_HISTORY_READ_PATH` | `<DATA_DIR>/online-player-history.db` | 管理中心在线峰值的只读数据源；测试服应指向正式服峰值库，未设置时读取本环境写入库 |
| `GRANDUMI_RECORD_DAILY_ACTIVE` | `0` | 是否将成功登录计入 UTC+8 日活；仅正式服显式设为 `1`，测试服保持 `0` 并只读正式服在线统计库 |
| `GRANDUMI_LEADER_STATS_READ_PATH` | `<DATA_DIR>/leader-stats.db` | 排行榜与管理中心每日场次的只读事实库；测试服指向正式服统计库，写入仍保留在本环境以避免多进程争用 |
| `GRANDUMI_RANKED_DB` | `<DATA_DIR>/ranked.db` | 单独覆盖标准排位积分、阵营与榜单数据库路径 |
| `GRANDUMI_RANKED_WILD_DB` | `<DATA_DIR>/ranked-wild.db` | 单独覆盖狂野排位积分、阵营与榜单数据库路径；必须与标准排位库隔离 |
| `GRANDUMI_REPLAY_DIR` | `<DATA_DIR>/Replays` | 单独覆盖录像目录 |
| `GRANDUMI_MATCH_LOG_DIR` | `<DATA_DIR>/MatchLogs` | 单独覆盖训练日志目录 |
| `GRANDUMI_PERSIST_DIR` | `<DATA_DIR>/Persist` | 单独覆盖未结束对局恢复日志目录 |
| `GRANDUMI_NODE_ID` | 主机名和进程号 | 指标与版本端点中的节点标识 |
| `GRANDUMI_SLOW_MS` | 80 | 单阶段慢样本阈值，单位毫秒 |
| `GRANDUMI_LATENCY_SUMMARY_SECONDS` | 60 | P50/P95/P99 控制台汇总周期 |
| `GRANDUMI_PROTOCOL_LOG` | 0 | 仅排障时开启逐协议日志 |
| `GRANDUMI_PRIVATE_SNAPSHOT_LOG` | 0 | 仅排障时开启私有快照日志 |

生产环境应保持后两项关闭，避免高频日志和私有牌面数据增加 I/O、延迟与信息暴露风险。

容量结论、告警阈值、压测方法和多节点边界见 `运维与容量.md`。
