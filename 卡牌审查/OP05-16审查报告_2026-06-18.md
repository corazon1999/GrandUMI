## 二、最该优先处理（确定级 BUG，影响对局正确性）

### 2.1 持续效果"全场误加成"（引擎已知坑：ContinuousEffect 的 Scope/Filter 被忽略，作用对象必须写进 Predicate）

- **OP07-087 巴斯卡比尔** — 卡面"**此角色**力量+3000"，Predicate 没写 `card.Id==selfId`，条件成立时全场（含领袖、对方）都+3000。改：Predicate 首条加 `card.Id==selfId`（参照 OP07-099）。
- **OP10-001 斯摩格** — 卡面"我方〈海军〉/〈班克禁区〉角色+1000"，过滤只写进 Scope.Filter，Predicate 仅判回合，对方回合时全场每张卡都+1000。改：把 `sideIdx==owner && (HasKeyword 海军||班克禁区)` 并入 Predicate。

> 根因同 `修复记录\EB04-007等_持续效果Scope被忽略致全场加成.md`。建议全库再 grep 一遍"只填 Scope 没在 Predicate 限定"的 ContinuousEffect。

### 2.2 守护/条件因数据用字不匹配而永不命中

- **OP10-032 达斯琪** — 离场守护用 `ColorList.Contains("绿")`，但绿色在数据里存为"**风**"，恒 false，守护完全失效。改：`Contains("风")`。
- **OP13-016 蒙奇·D·戈普** — 领袖名判断写 `NameIs("波特卡斯·D·艾斯")`（**卡**字），卡库统一用"波特**夹**斯·D·艾斯"，艾斯领袖下登场检索永不触发。改：把"卡"改"夹"。

### 2.3 目标错位（未定义 prompt 落入解释器兜底，返回对方角色）

- **OP14-084 Miss.全周日** — 第二目标用未定义的 `OwnTrashCharacterCostLe1`，落 default 返回 `opp.Characters`，从对方角色里登场。
- **OP14-093 Mr.4** — 用未定义的 `OwnTrashCharacterCostLe8`（解释器只到 Le7），同样落兜底返回对方角色。
- 改：在 `DslInterpreter.cs`（约 1290-1301 行）补这两个候选 prompt，并补《巴洛克工作室》特征过滤。

### 2.4 成本数量写错（少付/误判可支付性）

## 八、归纳的共性根因（建议从机制层一次性收口）

1. **ContinuousEffect 的 Scope/Filter 被快照构建器忽略** → 作用对象必须写进 Predicate，否则全场误加成（OP07-087、OP10-001，疑似全库还有）。
2. **同卡号重复脚本**反射注册相互覆盖、生效不确定（OP08×4、OP11×5、OP13×1）。建议加一个"启动时检测重复 CardNumber 并报错"的保护。
3. **DSL Choose/match 缺 filter** → 候选退化为任意（OP14 批）。
4. **解释器未定义的 prompt 落 default 返回对方角色**（OP14-084/093）——危险兜底，建议未识别 prompt 直接抛错而非静默返回对方场。
5. **事件卡只有 trigger/counter 没有 main** → 主要效果整段不执行（OP15 多张）。
6. **持续力量/费用类效果**若无 ContinuousEffect 注册就完全不生效（OP16-082/034/054）——无 effectTags 通用通道。
7. **条件式静态被动（阻挡者/费用/速攻/不离场）引擎通道缺口**（OP12 大量、OP16、OP13）。
8. **数据用字/颜色不一致**导致条件永不命中（OP13-016 夹/卡、OP10-032 绿/风）——建议加卡名/颜色常量校验。
9. **"公开"未 BroadcastReveal**（OP07/10/11 多张）——产品决策项，非逐卡 bug。
10. **触发节不支持 cost** 是既定惯例，勿误判为 bug；只在主要/反击段缺成本才算。
