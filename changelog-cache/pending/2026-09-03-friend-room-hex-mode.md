# 好友房支持海克斯模式

- 日期：2026-09-03
- 分类：新增
- 影响范围：好友房创建、准备房、海克斯对局与断线恢复
- 状态：已完成

## 玩家可见说明

- 创建好友房时现在可以选择普通模式或海克斯模式；玩法会在房间创建后锁定，加入者可在准备房确认本局玩法。
- 海克斯好友房会正常进行三轮私密强化选择，同时仍属于不影响公开排行与战绩的好友对局。

## 技术说明

- 将海克斯玩法作为好友房独立且不可变的服务端权威配置，贯穿创建、重复请求、加入、准备、开局与重连状态同步，不复用公开海克斯匹配的对局来源。
- 对局引擎、动作日志与确定性重放显式携带玩法开关；新好友房海克斯日志可在进程重启后恢复，旧公开海克斯日志继续兼容，旧好友房日志默认保持普通模式。
- 好友房继续使用 `RoomCode` / `Friendly` 来源，因此不会启用公开匹配操作棋钟，也不会进入公开 Leader 统计。

## 验证结果

- 服务端好友房、海克斯状态机与恢复定向测试 30/30 通过；服务端完整测试 1920 项通过、2 项环境性符号链接测试跳过、0 失败。
- 前端好友房海克斯契约测试 5/5 通过；前端完整测试 516/516 通过；TypeScript 检查与 Next.js 生产构建通过。
- 实际浏览器已验证桌面 1440×900、手机 390×844 与 360×780：玩法切换、创建/加入按钮和准备房锁定提示无横向溢出，触控区域均不小于 44×44px。
