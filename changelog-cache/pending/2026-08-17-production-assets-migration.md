# 正式服静态资源域名迁移

- 日期：2026-08-17
- 分类：优化
- 影响范围：正式服卡图、卡背、音频、特效与前端静态资源
- 状态：已完成

## 玩家可见说明

- 独立静态资源线路迁入当前正式服，卡图和卡背不再依赖旧服务器，并继续通过 Cloudflare 缓存稳定加载。

## 技术说明

- 新正式服新增 `assets.grand-umi.com` 独立 Nginx 站点，仅开放允许的只读静态路径和自定义卡背读取接口。
- 静态站点跟随 A/B 活动槽更新资源根目录，证书通过 HTTP-01 自动签发并由 Certbot 定时续期。
- 新正式服构建恢复使用独立资源域名，旧源站下线后不再形成资源依赖。

## 验证结果

- 相关 Node.js 回归测试 19 项全部通过。
- 五个涉及部署与切槽的 Shell 脚本已在新正式服通过 `bash -n` 语法检查。
- 新旧服务器卡图数量一致，抽样卡图、缩略图与默认卡背的 SHA-256 一致。
