# 关闭 QQ 群普通聊天 Agent

- 日期：2026-08-27
- 分类：优化
- 影响范围：QQ 群机器人普通成员 @聊天路由
- 状态：已完成

## 玩家可见说明

- 普通群成员 @机器人进行日常聊天时，机器人现在只会 @原发送者并固定回复“我只跟释迦大人聊天”，不再读取聊天图片或发起 Agent 对话；Bug 反馈、Bug 补充追问和其他群管理功能保持不变。

## 技术说明

- 将普通成员真实 @机器人的末端聊天路由改为使用 OneBot 安全消息段发送固定回复，不再下载媒体或写入普通聊天队列。
- 保留管理员真实 @的管理员 Agent 优先路由，以及人格切换、Bug 首次提交、Bug 追问和成员验证等既有前置路由。

## 验证结果

- `py -m unittest qq-bug-bot/tests/test_chat_agent.py`：33 项通过。
- `py -m unittest discover -s qq-bug-bot/tests -p 'test_*.py'`：112 项通过。
- 回归覆盖普通成员直接图片与合并转发图片均不下载、不入队且安全 @回复；管理员 Agent 仍下载媒体并进入管理员队列，普通成员 @提交 Bug 仍进入 Bug 检查队列。
