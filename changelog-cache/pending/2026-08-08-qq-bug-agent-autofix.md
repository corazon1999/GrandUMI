# QQ Bug Agent 自动修复闭环

- 日期：2026-08-08
- 分类：新增
- 影响范围：QQ Bug 反馈机器人、本机自动修复工作器、测试服部署流程
- 状态：已完成

## 玩家可见说明

- 玩家提交 `#bug` 后，明确且可确认的 Bug 会进入自动分析和修复流程；修复通过独立复核、测试并部署到测试服后，机器人会在原群 @ 玩家告知结果。功能需求或无法确定的问题会先在群内询问管理员，不会擅自决定玩法或产品方向。

## 技术说明

- 新增服务器 SQLite Agent 队列、SSH 桥接、本机 Codex 非交互工作器、结构化分诊与双重审查、安全路径/规模门禁、租约恢复、管理员 `#回复` 串行协议、服务器机器人回执、计划任务安装和机器人原子部署回滚脚本。自动流程明确排除正式服发布、仓库治理、CI、依赖、部署脚本、密钥与机器人自身改动。

## 验证结果

- 20 项 Python Agent/机器人单元测试通过，覆盖状态机、老库迁移、管理员身份与 @ 校验、串行问题、路径门禁、测试事件、Windows BOM/命令入口、Docker 部署/配置重载和提示注入边界。
- Codex JSON Schema、Python 语法、PowerShell 脚本语法和差异格式已通过静态验证；Posix Shell 脚本由测试服务器执行语法检查。
- 本机 Codex CLI 已通过真实代理连通与结构化 JSON Schema 自检。
- 服务器部署后检查容器运行状态与 `agent_bridge.py status`；只有本机 Codex 连通自检通过后才启用 Agent 队列。
