# 修复 ST13 兄弟检索费用范围

- 日期：2026-08-17
- 分类：修复
- 影响范围：ST13-013、ST13-019 的检索效果
- 状态：已完成

## 玩家可见说明

- ST13-013 与 ST13-019 现在只会检索费用不高于 5 的「萨波 / 波特夹斯·D·艾斯 / 蒙奇·D·路飞」，不再将 8 费路飞列为可选卡牌。

## 技术说明

- 将原本位于 `anyOf` 外层的费用上限下放到三个名称分支，使名称与费用条件在每个分支内同时生效。
- 同步覆盖 ST13-019 的主要效果与触发效果定义。

## 验证结果

- ST13-013 登场时检索：8 费路飞被排除，2 费路飞仍可选。
- ST13-019 主要阶段检索：8 费路飞被排除，2 费路飞仍可选。
