# 对局控制区整合与移动端布局优化

- 日期：2026-08-26
- 分类：优化
- 影响范围：对局页聊天、好友、观战人数、更多工具、超时延长与右侧行动区
- 状态：已完成

## 玩家可见说明

- 对局页低频工具现已统一收纳到左下角“更多”面板，设置、问题反馈、和棋、认输、屏蔽和举报入口更集中。
- 移除了对局中的独立“添加交战对手为好友”按钮，好友中心入口继续保留。
- 聊天、好友和非零观战人数固定在视觉左下角；按钮视觉更紧凑，同时保留适合触控的点击区域。
- 回合超时延长入口改为带说明的紧凑图标，并与左下控制区统一排布，避免遮挡其他入口或右侧核心行动按钮。

## 技术说明

- 以单一激活状态统一管理聊天、好友、观战列表和更多面板，避免浮层互相叠加。
- 更多面板复用既有和棋、认输、屏蔽、举报及反馈业务请求，观战者仅显示设置和反馈；核心对局行动仍保留在右侧行动区。
- 对局控制区按桌面与竖屏设备旋转后的视觉坐标分别锚定，并通过安全区变量兼容移动端边缘区域；交互容器不小于 44×44px。
- 移动端加时入口由控制区的同一 flex 布局管理；即使观战人数入口同时出现，也不会再因独立固定定位而与聊天按钮重叠。
- 反馈浮层统一进入对局覆盖层门户，设置入口在对局页由控制区接管，避免产生独立悬浮按钮。

## 验证结果

- `node --test tests/*.test.mjs`：367 项通过，0 项失败。
- `npx tsc --noEmit`：通过。
- `npm run build`：Next.js 16.2.6 生产构建通过。
- 自动化几何回归覆盖 390×844、360×780 竖屏旋转场景，验证 48px 交互区域、36px 视觉按钮、安全区锚点、与右侧行动区分离，以及存在观战者时加时入口与全部控制区按钮互不重叠。
- 桌面端 1280×720 实际浏览器检查通过：控制区位于视觉左下角，各入口交互区域为 48×48px，且不与右侧行动区重叠。
