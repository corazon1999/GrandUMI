# 运营处置与管理员安全中心

- 日期：2026-08-31
- 分类：新增
- 影响范围：玩家举报与申诉、限时处罚、管理员审计、一致性巡检、QQ 管理 Agent
- 状态：已完成

## 玩家可见说明

- 举报、对局聊天证据和申诉现在进入统一 Case 流程；违规处置均为有原因和到期时间的限时措施，可追踪处理状态。
- 管理员页面新增运营处置工作台，敏感操作必须经过一次性凭证和二次确认，降低误操作与账号被盗后的风险。

## 技术说明

- 新增统一 Case、证据保留、状态流转、负责人、处置结论、首响 P90、限时禁言/禁匹配/禁观战聊天、申诉和不可变哈希审计链。
- 一致性 Doctor 通过事务 outbox 同步昵称目录，支持租约恢复、指数重试、差异检测和受确认保护的修复；旧式管理员写操作在执行前必须先写审计意图。
- QQ 管理入口降为纯文本任务草稿；任务信封使用 HMAC 签名、固定命令白名单与持久化防重放，高风险动作拒绝 QQ 来源并要求两名不同批准人。普通 Bug 工作器不再包含合并或部署实现。

- 服务端完整测试 1688/1688、前端完整测试 429/429、生产构建与两档真实 Chrome 移动端验证均通过。
