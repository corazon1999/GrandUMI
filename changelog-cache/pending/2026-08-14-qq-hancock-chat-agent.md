# QQ 群女帝汉库克聊天 Agent

- 日期：2026-08-14
- 分类：新增、修复
- 影响范围：QQ 群机器人、`#聊天` 指令、本机 Agent 常驻任务

## 玩家可见说明

- 玩家现在可以在 QQ 群发送 `#聊天 你的消息`，唤起女帝波雅·汉库克性格的聊天 Agent；回复采用高傲、自信、优雅、护短且重感情的语气。
- 聊天支持少量同群上下文，并会限制单条长度、单人排队数和请求频率，避免刷屏与长时间排队。
- 修复本机 Agent 使用已失效代理端口而无法持续工作的配置问题。

## 技术说明

- 新增独立的 SQLite 聊天队列、SSH 队列桥、只读 Codex 工作器、结构化回复 Schema 和提示注入边界；聊天工作器不进入 Bug 修复工作区，不能修改代码或执行玩家夹带的工具指令。
- 新增 `GrandUMI-Chat-Agent` 隐藏计划任务安装器，登录后自动启动，异常退出由任务计划程序自动重启。
- 机器人通知循环可独立消费 Bug Agent 与聊天 Agent 结果，并通过 OneBot 安全消息段 @ 原玩家。
- 将本机 Agent 示例与当前运行配置的 Codex/Git 代理端口从不可用的 `7890` 修正为当前监听的 `7891`。
