# 修复 QQ 机器人 Agent 工作器命令路径失效

- 日期：2026-08-27
- 分类：修复
- 影响范围：QQ群普通聊天、Bug 描述检查与管理员 Agent
- 状态：已完成

## 玩家可见说明

- 修复机器人后台工具路径更新后，@机器人可能只收到“暂时无法回答”的问题；后台工具短暂不可用时，请求会保留等待恢复，不会在数秒内直接失败。

## 技术说明

- 常驻聊天工作器在每次调用前从权威配置文件重新读取 `codex_command`，但不会在任务处理中热切换服务器或远端队列，避免配置更新后旧进程继续使用失效路径。
- 领取有次数上限的远端任务前先检查 Codex 命令是否可解析；依赖不可用时不领取任务，防止同一基础设施故障快速耗尽三次尝试。
- 实际故障中的管理员工作器已在确认没有排队或已领取任务后安全重启，并加载有效的 Codex 绝对路径。

- 服务器数据库核对截图对应任务 #777：三次失败均为 `未找到 Codex 命令: codex`；重启前确认所有聊天与管理员队列均无 `queued` / `claimed` 在途任务。
