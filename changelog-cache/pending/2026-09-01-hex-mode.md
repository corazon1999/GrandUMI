# 航海王卡牌海克斯模式

- 日期：2026-09-01
- 分类：新增
- 影响范围：公开匹配、对局规则、断线恢复、回放、对局界面与手机竖屏布局
- 状态：已完成

## 玩家可见说明

- 新增独立的海克斯公开匹配模式。双方会在调度完成后、各自第 2 回合后和各自第 5 回合后进行私密三选一，并获得银色、金色和彩色海克斯能力。
- 支持 54 种海克斯效果、权威倒计时与超时自动选择；选定结果在双方锁定前不会向对手泄露。
- 新增双方已拥有海克斯展示与“三号船坞”双舞台区，电脑端和手机竖屏旋转布局均可分别操作两张舞台。
- 断线重连或服务重启后会按确定性随机序列恢复选秀、已拥有能力和对局进度，重复或迟到的选择不会重复结算。
- 低力量角色受到“不能横置”保护时，不能被用于攻击、阻挡或横置费用，也不会因“横置登场”效果错误进入横置状态。
- “复制下一次登场时／被击倒时效果”只会在原效果实际发动后消耗；条件不成立、费用无法支付或没有合法目标时会继续保留。

## 技术说明

- 服务端新增 Hex 匹配类型、独立匹配队列、54 项权威规则目录、分阶段选秀状态机、私密候选快照、确定性随机事件与系统超时动作。
- 选秀动作、截止时间和系统自动选择进入恢复日志；获得时结算使用持久化步骤游标，根能力归属先行提交，重试与日志重放从未完成步骤继续且不会重复发放资源。
- 横置操作统一经过状态感知的合法性守卫；作为费用时先完成全部目标预检，任一步不合法即不改变状态，作为效果时仍按尽力执行语义处理。
- 登场时与被击倒时复制效果以权威状态变化、有效选择或显式效果揭示作为“实际发动”证据，静默条件退出不会误消耗复制次数。
- 扩展玩家状态、快照、动作校验、舞台出牌和卡效定位以支持第二舞台，并保持旧版单舞台快照字段兼容。
- 前端新增选秀遮罩、服务端校准倒计时、锁定状态、已拥有列表、海克斯匹配入口和双舞台交互。

## 验证结果

- 后端完整测试：1856 项通过、2 项因当前平台不支持符号链接场景而跳过、0 项失败。
- 海克斯效果与状态机最新关键回归：74 项全部通过；覆盖横置费用原子预检、攻击与阻挡、横置登场、复制效果实际发动判定、获得时结算故障注入、幂等重试及日志重放。
- 前端完整 Node 测试：466 项全部通过；海克斯与布局定向测试包含 390×844、360×780、44px 触控区和安全区断言。
- `npx tsc --noEmit` 与 Next.js 16.2.6 生产构建均通过。
- 已完成真实浏览器复核：桌面端海克斯匹配入口正常；390×844 与 360×780 手机竖屏均无横向溢出，关键按钮触控区不小于 44×44px，对局画布可自动旋转且悬浮控件保持在安全区内。
