# 完整好友系统

- 日期：2026-08-09
- 分类：新增
- 影响范围：大厅、玩家社交、友谊战邀请、玩家数据持久化
- 状态：已完成

## 玩家可见说明

- 大厅新增好友中心，可按账号或昵称搜索玩家、发送和撤回好友申请，并处理收到的申请。
- 好友列表会实时显示在线与对战状态，支持直接邀请空闲好友进行友谊战，也可安全删除好友。
- 好友关系和待处理申请会云端保存，测试服与正式服使用同一玩家数据时可共享好友数据。

## 技术说明

- 玩家 SQLite 数据库新增好友关系与双向唯一好友申请表，并提供搜索、申请、自动互加、接受、拒绝、撤回和删除事务。
- WebSocket 新增好友列表、搜索和关系变更协议；登录、上下线及关系变化时向相关在线玩家实时推送最新快照。
- 前端新增好友中心、申请角标、实时关系状态和现有友谊战邀请入口，并在桌面和窄屏大厅中提供好友入口。
