# 修复手机竖屏卡组编辑器布局

- 日期：2026-08-10
- 分类：修复
- 影响范围：卡组编辑器、手机端竖屏布局
- 状态：已完成

## 玩家可见说明

- 手机竖屏编辑卡组时，牌池与卡组现在分别占满屏幕宽度，可通过顶部标签快速切换；筛选条件改为按需展开，不再挤占牌池空间。
- 牌池、卡组列表和底部操作区均适配动态视口与手机安全区，卡牌选择、卡组管理和保存操作在竖屏下保持可见可用。

## 技术说明

- 小于中等断点时将桌面三栏布局切换为移动端单主视图，增加牌池/卡组视图导航和覆盖式筛选面板。
- 桌面断点继续保留筛选栏、牌池和卡组三栏布局；移动端主内容增加最小尺寸约束和底部安全区处理。
- 为筛选面板增加移动端关闭入口，并补充移动/桌面布局回归测试。

## 验证结果

- 通过全部前端自动化测试，共 64 项测试通过，覆盖卡组编辑器、主页侧栏、卡组广场、对局竖屏旋转和浮层布局等手机端相关界面。
- 通过 TypeScript `tsc --noEmit` 类型检查。
- 通过 Next.js 16.2.6 生产构建，`/deck-editor` 静态页面生成成功。
- 核对 390×844 与 430×932 手机竖屏断点规则：默认牌池占满可用宽度，筛选为覆盖面板，卡组视图独立显示，桌面三栏样式不受影响。
