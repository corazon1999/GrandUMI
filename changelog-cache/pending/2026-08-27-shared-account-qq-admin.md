# 正式服与测试服共享账号及 QQ 绑定管理

- 日期：2026-08-27
- 分类：新增
- 影响范围：账号登录、QQ 准入、管理员玩家管理、测试服与正式服账号同步
- 状态：已完成

## 玩家可见说明

- 正式服与测试服现在共用账号、密码、登录会话和 QQ 绑定；管理员可通过共享检索目录按最近同步的昵称查找账号。两个环境的玩法显示昵称、牌组和战绩仍各自独立。
- 管理员可以按账号、昵称或 QQ 号查找玩家，并安全地绑定、更换或解绑 QQ。
- 管理员调整 QQ 绑定后，旧登录会话会失效；已经开始的对局可完成当前一局，但不能继续进入大厅或发起新对局。

## 技术说明

- 新增独立共享账号 SQLite 权威库及停写迁移流程：首次切换会同时停止正式服与测试服后端写入，以正式服账号为权威、测试服仅补充不冲突账号；测试服预激活期间已经写入本地共享视图的新密码、会话、白名单和绑定也会纳入迁移。迁移完成后先原子提交不可回滚的共享权威标记，再启动新版正式后端，杜绝进程在切流窗口退出后回退旧本地账号库。正式服务只有在激活标记、准备标记、非空数据库和源数据迁移审计同时有效时才能启动，不能自行从正式玩法库建库。
- 共享目录昵称仅用于跨环境管理员检索和新环境首次物化；已经存在的玩法显示昵称不会跨环境互相覆盖。目录同步失败时会明确提示，而不会把当前环境已经提交的改名伪装成整体回滚。
- QQ 绑定更新使用唯一约束、修订号比较交换、UUID 幂等请求和即时事务；会话撤销、管理员审计与跨进程安全事件在同一事务内提交。
- 登录密码校验和哈希计算移出全局写事务，跨环境登录不会因慢速密码计算串行阻塞；对局恢复仅允许回到仍在进行的当前对局。
- 生产切槽、首次激活、测试服部署、服务单元和快照流程均增加共享账号库兼容边界与失败保护。
