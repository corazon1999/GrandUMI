# 动态特效默认静态与手动开关

- 日期：2026-10-19
- 分类：优化
- 影响范围：大厅、设置、对局与回放的视觉特效及手机布局
- 状态：已完成

## 玩家可见说明

- 默认使用静态显示，减少持续光效带来的渲染负担；已有用户也默认进入静态模式。
- 设置新增“动态特效”开关，可手动开启大厅装饰、卡牌光效和对局动画，并记住开关与速度选择。
- 静态模式保留卡牌词条、攻击连线、必要的公开卡牌及胜负结果。
- 设置适配电脑、手机竖屏与自动旋转的对局；弹窗打开时收起全屏按钮，避免遮挡关闭操作。

## 技术说明

- 新增默认关闭的 visualEffectsEnabled 持久化设置，旧设置只有明确开启新开关后才启用动态效果。
- 在首屏、全局 CSS 和 Motion 动画配置统一应用静态策略，关键词、SVG 攻击粒子、领袖分层光效及演出共用动态设置与实时系统减少动态效果订阅。
- 对局动画速度通过有效设置读取；关闭时停止卡牌飞行与效果演出，已经播放的领袖开场立即退出，骰子直接显示权威结果。
- 新增受环境保护的真实牌桌验证夹具，将特效迁移、持久化和真实浏览器检查接入既有验证流程。

## 验证结果

- 前端全量测试：633 项，631 项通过、2 项既有条件跳过、0 项失败。
- 生产构建通过；动态特效专项浏览器检查通过 1440×900、390×844、360×780。
- 验证默认静态、开启恢复光效与 SVG 粒子、关闭停止无限动画、刷新保留开关和速度，以及系统减少动态效果实时变化。
- 验证静态牌桌采样不持续重算样式，词条与攻击连线保持显示，关闭开关可退出正在播放的开场演出。
- 实际截图检查电脑、大厅手机竖屏及自动旋转对局设置；开关至少 44×44px、无横向溢出，关闭按钮未被全屏按钮遮挡。
- 既有真实浏览器回归通过，包括两档手机竖屏及 344×582 窄屏检查。
