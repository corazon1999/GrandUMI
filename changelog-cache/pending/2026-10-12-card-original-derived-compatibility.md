# 补齐仅有派生卡图系列的旧原图链接

- 日期：2026-10-12
- 分类：修复
- 影响范围：旧卡图链接及资源错误响应
- 状态：已完成

## 玩家可见说明

- 部分系列只有高清图或缩略图时，旧卡图链接也能显示同一张卡。

## 技术说明

- 外网验收发现 OP17 原图库未收录该系列，但高清和缩略资源齐全。Nginx 原图兼容路径依次查找原文件、同名 WebP、高清 WebP、缩略 WebP，包括直接请求原图 WebP 的情况。
- 源站错误响应增加 private、禁止保存和重新验证指令，同时明确下发 CDN 与 Cloudflare 的禁止缓存头，避免仅依靠普通 Cache-Control。
- Cloudflare 可覆盖源站缓存策略，外网响应仍需单独核对；本项不包含修改 Cloudflare 全站配置或正式环境。

## 验证结果

- 三份配置在隔离 Nginx 1.24 实例中通过语法与实际 HTTP 行为检查。
- 有原图、仅高清、仅缩略三种情况的旧 PNG 及原 WebP 链接均返回正确图片和 MIME。
- 完全缺失时返回 404，并下发普通缓存、CDN 和 Cloudflare 的禁止保存指令；JSON 压缩验证通过。
