# 组卡页返回大厅不再掉登录态

- 日期：2026-08-26
- 分类：修复
- 影响范围：组卡页、大厅登录会话、桌面端与手机竖屏返回入口
- 状态：已完成

## 玩家可见说明

- 从组卡页返回大厅时会直接保持当前登录状态，不再闪现或停留在登录界面；桌面和手机入口均已修复。

## 技术说明

- 组卡编辑器的两个返回入口改用 Next.js 客户端路由，让根布局中的登录 store 与 WebSocket 连接在路由切换中持续挂载。本次未改动整页刷新或对局重连的会话令牌恢复逻辑，异地登录阻断与令牌保护保持不变。
- 回归测试改为解析 TSX 语法树，明确检查桌面和手机入口都使用客户端链接，且不再触发整页恢复标记。
