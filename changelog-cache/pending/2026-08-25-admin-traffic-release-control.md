# 管理中心在线峰值与版本发布控制

- 日期：2026-08-25
- 分类：新增
- 影响范围：管理员控制台、在线统计、测试服部署、正式服发布
- 状态：已完成

## 玩家可见说明

- 管理员点击“在线玩家”状态卡后，可切换查看近一周或近一月的每日在线峰值趋势。
- 管理中心新增测试服和正式服版本发布入口，可查看当前状态并将对应环境更新到远端最新版本。

## 技术说明

- 服务端按 UTC+8 自然日将在线峰值持久化到独立 SQLite 数据库，并在登录人数变化及每分钟采样时更新当日峰值。
- 发布请求由管理员 WebSocket 权限再次校验，普通服务账号仅能写入受限队列；systemd 根执行器只接受 `test` 与 `production` 两种固定任务，不接收网页传入的命令或提交号。
- 测试服复用现有独立数据部署与回滚流程；正式服复用 A/B 预构建和切槽流程，并强制校验最新提交已部署测试服、待发布日志已归档、维护模式已启用且进行中房间为零。
- 正式发布请求在零房间时自动进入维护模式；失败时保留维护状态，避免玩家在人工排查期间开始新对局。

## 验证结果

- 后端全量 1236 项测试通过；新增在线峰值持久化与发布队列测试 4 项通过。
- `npm run build` 通过；管理面板和部署链相关 23 项前端回归测试通过。
- 五份 Bash 部署脚本均在目标服务器使用 `bash -n` 完成只读语法校验。
- 浏览器实测 390×844 与 360×780：页面无横向溢出，峰值图和发布区保持可滚动单列布局，统计周期与发布按钮高度均为 44px。
- 前端全量 297 项中 290 项通过；其余 7 项为卡牌费用、对局状态和举报入口的既有断言失败，涉及文件不在本次改动范围内。
