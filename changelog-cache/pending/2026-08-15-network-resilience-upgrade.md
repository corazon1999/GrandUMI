# 网络韧性与对局动作幂等升级

- 日期：2026-08-15
- 分类：优化
- 影响范围：登录、WebSocket 重连、浏览器休眠恢复、对局操作、网络诊断、新香港候选服部署

## 玩家可见说明

网络短暂波动、切换线路或手机浏览器从后台恢复时，连接会更快识别失效线路并自动恢复；重复到达的对局操作不会被执行两次，降低弱网下重复出牌或重复结算风险。

## 技术说明

- 增加可热更新的同源线路清单、最近成功线路记忆、连续失败熔断、带随机抖动的退避和前台唤醒心跳。
- 增加按入口聚合的握手、RTT、失败和重连诊断，服务端不接收账号、令牌等敏感信息。
- 服务端为每个房间增加有界 TTL requestId 幂等窗口；重复请求在房间串行队列中返回权威快照。
- 将错误的 2 Mbps 网络整形默认值修正为 60 Mbps，并增加只允许新香港 IP 的候选服引导与部署脚本。

## 验证结果

- 前端 TypeScript 检查通过。
- Next.js 生产构建通过。
- WebSocket 线路专项测试 6/6 通过。
- 服务端测试 933/933 通过，其中新增幂等窗口测试 3 项。
