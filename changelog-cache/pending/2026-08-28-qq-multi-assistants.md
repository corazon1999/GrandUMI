# QQ 三助理与管理员权限隔离

- 日期：2026-08-28
- 分类：新增
- 影响范围：QQ群助理、管理员本机 Agent 调遣、NapCat 部署与断线恢复
- 状态：已完成

## 玩家可见说明

- 新增 `s-鹰`、`s-鲨` 两名 QQ 副助理；与原有 `s-蛇` 一样，只有 QQ `651846226` 真正 @对应助理时才会调遣本机 Agent。
- `s-鹰`、`s-鲨` 不参与普通 Bug 收集、加群审批、新人验证或白名单同步；普通群功能继续只由 `s-蛇` 处理，避免重复记录和重复回复。
- 助理断线或重启后，处理结果仍会由最初被 @的账号回复；重复投递同一条 QQ 消息不会重复执行管理员任务。

## 技术说明

- 机器人兼容原单连接配置，并新增一个主助理加多个 `admin_only` 副助理的独立连接生命周期；单个副助理故障不会中断主连接。
- 管理员身份固定为 OneBot 原始事件 `user_id=651846226`，且必须存在指向事件 `self_id` 的顶层结构化 `at` 段；正文、CQ 字符串、截图、引用和转发均不能作为身份凭据。
- SQLite 管理员队列新增来源助理与 OneBot 消息去重键，历史上下文、完成结果和重启恢复均按来源助理隔离；群回执改为等待 OneBot 成功确认后再标记已发送。
- Compose 新增 `s-鹰`、`s-鲨` 两套独立 NapCat 容器、设备身份、WebUI 端口和持久化卷，并把三名助理的预期 QQ 固定为 `3215228879`、`3430685803`、`184689168`。两个副助理在配置样例中默认关闭，只有完成登录与 `get_login_info` 核验后才能启用。
