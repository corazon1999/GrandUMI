# 挂机提醒确认脱困

- 日期：2026-09-01
- 分类：修复
- 影响范围：对局挂机提醒、效果选择期间的权威快照、断网或响应超时后的操作恢复
- 状态：已完成

## 玩家可见说明

- 点击“我还在，继续对局”后会及时回到可操作的对局界面，不再长时间卡在“正在确认…”。网络回应异常时，客户端也会自动重取对局状态并恢复按钮，允许玩家继续尝试。

## 技术说明

- 将挂机提醒与在线确认登记为效果批次的即时快照屏障，即使异步效果或 Prompt 仍处于挂起批次，也会立即下发服务端权威结果。
- 挂机确认增加 5 秒响应安全网；超时时只轻量重取权威快照，不回滚或解锁其他卡牌动作的乐观状态。

## 验证结果

- 前端挂机提醒、排位棋钟与服务端倒计时专项回归 16/16 通过；服务端操作棋钟回归 25/25 通过，包含新增的效果批次挂起场景。
- `npm run build` 生产构建通过。
- 实际浏览器验证 1280×720、390×844 和 360×780；两档手机竖屏均正常自动旋转横屏画布，主要按钮完整可见、可点击，无页面溢出，360×780 下触控短边约 44.31px。
