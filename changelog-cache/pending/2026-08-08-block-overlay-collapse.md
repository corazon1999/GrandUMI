# 阻挡步骤面板支持收起

- 日期：2026-08-08
- 分类：优化
- 影响范围：对局中的阻挡步骤界面
- 状态：已完成

## 玩家可见说明

- 阻挡步骤面板现在可以临时隐藏，方便查看自己的手牌和牌桌；隐藏后可通过右下角按钮随时恢复面板。

## 技术说明

- 为阻挡步骤弹层增加本地收起状态、隐藏入口和恢复入口；离开阻挡步骤时自动恢复默认展开状态，不改变任何阻挡决策或战斗请求。
- 审查了其他对局全屏或浮动面板：效果选择面板已有隐藏与恢复入口，墓地、生命区、反馈和 GM 面板已有关闭入口；其余遮罩属于开局、连接或结算流程，无需增加临时隐藏能力。

## 验证结果

- `npx tsc --noEmit --incremental false` 通过。
- `npm run build` 通过，Next.js 生产构建及 TypeScript 检查成功。
- 本地客户端页面可正常加载；因本地后端未连接，未进行实战阻挡步骤的浏览器交互复现。
