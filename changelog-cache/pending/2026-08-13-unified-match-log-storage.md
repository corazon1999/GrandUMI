# 对局录像与日志统一存储

- 日期：2026-08-13
- 分类：优化
- 影响范围：服务端对局持久化、服务器磁盘空间
- 状态：已完成

## 玩家可见说明

- 对局回放功能保持不变；服务器不再为同一局重复保存录像与对局日志，降低磁盘占用并延缓空间耗尽。

## 技术说明

- 移除服务端 `ReplayRecorder` 及房间创建、恢复、结束时的重复录像生命周期，只保留包含公开快照和审计事件的统一 `MatchLogs`。
- 玩家回放继续由浏览器 IndexedDB 保存；未来需要服务端公开回放时，可从日志中的 `public_snapshot` 安全导出。

## 验证结果

- 隔离验证环境完成编译；持久化与延迟测试 13/13 通过，稳定服务端测试集 879/879 通过，两个并行 Prompt 时序用例单独复跑 2/2 通过。
- 完整套件另有 2 项测试按项目规范硬性要求 Windows `E:` 盘，无法在 Linux 隔离环境运行，与本次持久化改动无关。
- 生产服务器 9,132 份旧录像均存在同名对局日志，无唯一录像文件；清理前占用约 5.8 GB。
