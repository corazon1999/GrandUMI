# 管理员海克斯品质面板

- 日期：2026-09-02
- 分类：新增
- 影响范围：管理员面板、海克斯玩法、新对局配置、测试服与正式服配置发布
- 状态：已完成

## 玩家可见说明

- 管理员现在可以在专用海克斯面板中查看全部海克斯、逐项调整品质，并将经过确认的配置一键发布到所选环境。
- 配置发布只影响之后创建的新海克斯对局；已经开始的对局继续使用开局时锁定的配置，断线恢复和回放也保持一致。

## 技术说明

- 新增带版本、摘要和完整品质映射的权威海克斯配置；新房间在创建时固定配置，状态快照、私有快照和恢复日志均携带对应版本，避免发布期间的在局漂移。
- 管理端采用共享草稿、乐观并发版本、基线摘要和一次性高风险确认凭证；三个常规品质池必须严格各保持 18 个，管理员需用调换方式维持候选容量。重复请求可幂等返回，陈旧草稿或基线变化会拒绝发布。
- 发布脚本对测试服与正式服使用独立目标、全局文件锁、严格 JSON 校验、原子替换和目录同步，并保持海克斯配置发布与整站部署相互独立。

## 验证结果

- 服务端全量测试通过：1914 项通过、2 项因测试环境不支持符号链接而按既有条件跳过、0 项失败；海克斯状态机、管理员发布协调器和运营权限定向测试 25 项全部通过。
- 前端全量测试 502 项全部通过；海克斯面板及管理员发布组合定向测试 11 项全部通过，TypeScript 类型检查与 Next.js 生产构建通过。
- 协议契约校验、部署脚本 Bash 语法检查及静态安全断言通过。
- 在实际浏览器中验证 390×844 与 360×780 两档手机竖屏：无水平溢出，全部主要控件触控尺寸不小于 44px，并验证品质修改、环境切换和发布确认入口。
