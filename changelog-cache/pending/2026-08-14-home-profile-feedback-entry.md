# 首页“我的”反馈入口

- 日期：2026-08-14
- 分类：新增
- 影响范围：首页“我的”页面、Bug 与建议反馈弹窗
- 状态：已完成

## 玩家可见说明

- 首页“我的”页面新增“反馈 Bug 和建议”入口，手机玩家无需键盘快捷键即可直接提交问题或建议。
- 反馈弹窗同步适配手机安全区与竖屏尺寸，关闭、分类及发送按钮均提供不小于 44×44 像素的触控区域。

## 技术说明

- 复用大厅现有反馈窗口与提交协议，通过主页状态将“我的”页面按钮连接到同一弹窗，保留页面信息、账号与网络诊断数据的自动附带能力。
- 大厅反馈标题不再强调 F 快捷键；对局内仍保留原有 F 键提示和入口。
- 补充简体中文、英文与日文界面文案映射，并增加主页入口、安全区及触控尺寸回归测试。

## 验证结果

- `node --test tests/player-feedback-prompt-ui.test.mjs`：通过（8/8）。
- `npm run build`：通过，Next.js 生产构建与 TypeScript 检查成功。
- 浏览器实际检查：电脑端及 `390×844`、`360×780` 手机竖屏下入口完整可见；入口高度 80px，反馈弹窗主要按钮高度均为 44px，未与底部导航重叠。
- 前端全量测试共 162 项，159 项通过；其余 3 项为本任务前已存在的旧断言，分别仍要求全屏按钮只在手机显示、断线宽限为 120 秒、回合动画固定 2200ms，与当前已实现规则不符，与本次改动无关。
