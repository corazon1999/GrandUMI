# 新增网咖群激活码领取

- 日期：2026-09-20
- 分类：新增
- 影响范围：QQ 机器人、网咖群激活码库存与领取
- 状态：已完成

## 玩家可见说明

- 在指定的两个网咖群中，群成员发送纯文本“领码”后，机器人会 @领取人并发送一个尚未发出的 BEAST 激活码；库存耗尽时会给出明确提示。
- 同一条消息不会因并发、重放或机器人重启重复领取；同一成员发送新的“领码”消息仍可再次领取。

## 技术说明

- 固定由官方主助理处理两个目标群，命令只接受规范化后的顶层纯文本；领取前实时核验群成员与机器人标记，拒绝引用、转发、附件、CQ 内容、机器人事件和缺少可信消息号的事件。
- 使用独立 SQLite 库在 OneBot 发送前原子预占库存，并持久记录来源群、领取 QQ、来源消息号、发送结果与 OneBot 返回消息号；明确失败或未知结果均不会将已占用激活码放回库存。
- 新增仅从标准输入读取的一次性幂等导入工具，导入前校验数量、格式、唯一性与 SHA-256，并生成权限受限的导入前后备份。真实激活码不进入代码仓库、配置、日志或测试数据。

## 验证结果

- 新增 18 项定向测试，覆盖固定群与账号边界、精确命令、实时成员与机器人核验、并发分配、消息重放、同成员新消息、成功/明确失败/未知结果、崩溃恢复、库存耗尽、导入幂等与格式校验、敏感内容不落日志、旧反馈库兼容。
- QQ 机器人完整测试集 253 项通过；部署脚本通过 Shell 与 PowerShell 语法检查，样例配置通过 JSON 解析。
- 只读核验主助理 `3215228879` 已加入两个目标群，现网 NapCat 的两次成员响应均提供可信布尔 `is_robot` 字段；未向真实群发送测试消息，也未在验证阶段消耗真实激活码。
