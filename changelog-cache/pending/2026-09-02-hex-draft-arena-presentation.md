# 重制海克斯三选一界面与交互反馈

- 日期：2026-09-02
- 分类：优化
- 影响范围：海克斯模式三选一界面、刷新操作、对局音效与手机竖屏旋转布局
- 状态：已完成

## 玩家可见说明

- 海克斯三选一改为三张竖向强化卡，按银色、金色和彩色品质显示专属边框、辉光、符文图标、名称与完整效果。
- 每张候选卡下方都有独立的图标化刷新按钮，并会明确显示刷新机会可用或已使用。
- 面板出现、刷新成功和选择锁定时会播放对应提示音，并继续遵守音效音量、静音和浏览器播放授权设置。
- 选择期间可用“查看场上”或 Esc 暂时隐藏面板；倒计时与候选状态会继续保留，随时可从安全区内的按钮重新打开，新一轮选择会自动重新显示。

## 技术说明

- 保留服务端权威候选、轮次令牌、刷新机会、锁定状态、截止时间与超时恢复流程；隐藏仅是按选秀轮次管理的客户端展示状态，不暂停计时，也不改写任何玩法数据。
- 以 CSS、内联 SVG 和现有响应式容器实现原创的竞技场式卡框、六类确定性符文图样与品质视觉，没有复制或引入第三方游戏图像资产。
- 新增三段本地合成的原创 Ogg 音效，并接入统一音频清单和播放引擎；只在权威快照首次出现、刷新结果变化或选择锁定时播放，隐藏期间仍推进音效状态游标，避免重开时补播过时反馈。
- 旋转画布下将隐藏和重开入口调整到物理右上安全区，避开物理右下的全屏与设置控件；交互按钮使用放大后的设计触控尺寸，保证 360×780 缩放后短边仍大于 44px。

## 验证结果

- `node --test tests/*.test.mjs`：通过 483 项，失败 0 项。
- `npm run check:audio`：通过，24 个 Ogg 音效文件完整，共 257811 字节。
- `npm run build`：通过，Next.js 生产构建、TypeScript 检查与静态页面生成均成功。
- 浏览器实测：桌面 `1440×900` 下卡体约为 `264×406px`，宽高比约 `0.65`；`390×844` 与 `360×780` 均进入自动旋转横屏画布，紧凑卡体逻辑尺寸约为 `160×232px`、宽高比约 `0.69`，三张卡完整且无横向溢出。
- 隐藏后倒计时从 242 秒继续下降至 240 秒，点击重开与 Esc 往返均正常；`360×780` 下隐藏和刷新按钮物理短边约 `46px`，重开按钮位于物理右上且不与全屏、设置控件重叠。刷新态三个按钮均明确显示已使用且被刷新项有标记，锁定态选择与刷新全部禁用并显示权威结算；干净浏览器标签页控制台无警告或错误。
