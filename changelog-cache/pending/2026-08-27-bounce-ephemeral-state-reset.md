# 回手卡牌重新登场时清除临时状态

- 日期：2026-08-27
- 分类：修复
- 影响范围：角色与舞台回手、重新登场、临时限制与重复请求保护
- 状态：已完成

## 玩家可见说明

- 卡牌返回手牌后再登场时，不会继续保留上一次在场期间获得的临时限制；例如 ST32-002 重新登场后可正常被横置。
- 同一张卡牌的重复回手结算不会在手牌中生成重复卡牌。

## 技术说明

- 回手操作改为复用统一的离场瞬时状态重置，并补齐临时名称、临时属性与回合状态字段的清理。
- 只有确实从当前玩家角色区或舞台区移除成功的实例才会进入手牌，使迟到、重复或所有者不匹配的回手请求保持幂等。

## 验证结果

- 卡牌定向回归 19/19 通过，覆盖 ST32-002 回手再登场、限制清除和重复回手幂等。
- 相关离场与卡牌效果回归 60/60、服务端完整测试 1471/1471 通过。
