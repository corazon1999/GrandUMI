# 测试服与正式服共享卡组数据

- 日期：2026-08-09
- 分类：优化
- 影响范围：测试服、正式服、账号卡组云端同步
- 状态：已完成

## 玩家可见说明

- 使用同一账号登录测试服或正式服时，现在可以看到并使用同一套云端卡组，不再需要在两个环境分别维护卡组。

## 技术说明

- 测试服后端通过 `GRANDUMI_PLAYER_DB` 指向正式服玩家数据库，使两个环境共用玩家资料、已选卡组和卡组内容。
- 排行榜、录像、对局日志和对局恢复数据仍保持各自原有配置，不随本次调整合并。
- 原测试服玩家数据库保留在原路径，未删除或覆盖，可用于必要时回退。

## 验证结果

- `dotnet test .\服务端WebSocket.Tests\GrandUMIServer.Tests.csproj -c Release --nologo`：680 项全部通过。
- 使用测试服主机的 `systemd-analyze verify` 校验更新后的服务单元，配置合法。
- 部署前只读核对确认正式服玩家数据库路径存在，且正式服、测试服后端当前均为运行状态。
