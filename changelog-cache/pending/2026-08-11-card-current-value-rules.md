# 修正卡牌效果的费用与力量判定口径

- 日期：2026-08-11
- 分类：修复
- 影响范围：对局内按费用或力量选择、KO、横置、回手、回牌组及条件判定的卡牌效果
- 状态：已完成

## 玩家可见说明

- 修复大量费用与力量类效果错误使用卡面数值的问题：效果文本未写“原本”时，现在会正确计入临时修正、持续效果和咚!!带来的当前数值；明确写有“原本”的效果仍按卡面数值结算。
- 修复降低高费用角色后仍无法被低费用效果选中、提高低费用角色后仍被错误选中，以及力量变化后 KO、横置等目标范围未同步更新的问题。

## 技术说明

- 为场上卡统一使用包含临时修正、持续光环与咚!!的当前费用/力量入口，并为按当前费用筛选自身作用对象的持续效果增加排除自身来源的递归安全计算。
- 扫描手写效果脚本并修正 179 处场上取值，涉及 150 个脚本文件；同时修正 OP12-029 的混合当前/原本费用语义与 EB01-061 的原本力量复制实现。
- 复核 61 份 DSL 定义中的 179 个旧式场上过滤项：160 项未写“原本”的效果改按当前值，19 项明确“原本”的效果增加显式标记并保留卡面值；手牌、卡组、废弃区和生命区仍按卡面值。

## 验证结果

- 定向回归测试通过：12/12，覆盖费用上调/下调、力量临时与持续修正、明确“原本”的反例、复制当前力量及持续费用自递归保护。
- 服务端完整自动化测试通过：831/831，0 失败、0 跳过。
- 61 份 DSL JSON 均通过解析；静态复扫未发现脚本继续直接调用缺少持续效果的 `CardInstance.CurrentCost()` / `CurrentPower()`。
