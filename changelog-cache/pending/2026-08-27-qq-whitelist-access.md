# QQ 群白名单账号准入

- 日期：2026-08-27
- 分类：新增
- 影响范围：账号登录、QQ 绑定、管理员白名单导入、匹配与好友对局准入
- 状态：已完成

## 玩家可见说明

- 所有新旧账号在完成密码验证后，都必须一次性绑定当前 QQ 群白名单内的 QQ 号；同一 QQ 号只能绑定一个账号，玩家不能自行改绑或解绑。
- 每次登录、断线恢复以及进入匹配、房间、邀请对局或下一局前都会重新校验群白名单资格；QQ 被移出名单后将无法继续登录或开始新对局，已经开始的本局不会被强制中断。
- 管理员后台新增 QQ 群成员 JSON 全量导入，支持常见数组和包装格式，并展示去重、新增、移除及已绑定移出人数摘要。

## 技术说明

- 在玩家 SQLite 中新增白名单版本、QQ 唯一绑定、导入摘要审计和首次初始化管理员快照；迁移幂等，且不改动既有账号密码与资料。
- 登录凭据验证与 QQ 权威准入分层处理，未初始化时只允许迁移时已经存在的授权管理员进入受限初始化会话；首份名单导入后管理员本身也必须绑定有效 QQ。
- 白名单替换、账号绑定和最终新对局注册共享数据库路径级读写门锁，避免导入与开局并发时出现资格穿透；导入后会清理不合格玩家的匹配、邀请及赛前房间状态。
- 原始 JSON 只在本次校验期间使用，审计仅保存操作者、时间、版本和人数摘要；玩家管理界面只显示脱敏 QQ。

- QQ 登录、管理员导入及协议定向前端测试 18/18 通过；TypeScript 检查与 Next.js 生产构建通过。
- 前端完整测试仅有 5 项因隔离验证副本缺少既有卡图资源而失败，与本功能无关；其余用例通过。
- 实际浏览器验证非白名单拒绝、名单内绑定登录、移出名单后拒绝令牌恢复、管理员 JSON 预览与全量替换均生效。
- 实际浏览器检查 390×844 与 360×780：无横向溢出，QQ 绑定和白名单导入内容可滚动，关键触控按钮高度为 44–48px。
