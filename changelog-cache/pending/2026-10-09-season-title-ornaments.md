# 赛季称号背景纹饰精细化

- 日期：2026-10-09
- 分类：优化
- 影响范围：称号中心、当前佩戴称号、排行榜与排位对局称号展示
- 状态：已完成

## 玩家可见说明

- 称号卡片的空心圆和简单方框升级为围绕主徽章展开的精细纹饰，加入金属刻度、对称雕花和宝石节点。
- 海贼王使用放射冠冕，四皇使用帝冠饰框；海军元帅使用航海仪，大将使用冰晶切面；世界之王使用日蚀星轨，五老星使用五曜星阵。
- 纹饰只缓慢转动内部刻度，主徽章、饰框和文字保持稳定；手机窄卡片保留完整主环，对局中的小型称号降低背景亮度。

## 技术说明

- 用独立 SVG 纹饰替代旧 honorOrbit 纯 CSS 圆圈/方框，每个实例使用独立渐变标识并继承称号色板。
- 背景定位与主徽章居中对齐，两侧雕花采用镜像结构；装饰设置 aria-hidden、focusable=false 和 pointer-events:none。
- 标准徽标、称号中心大卡片和对局小徽标分别控制纹饰尺寸与透明度，兼容减少动态效果设置。
- 浏览器回归新增六类纹饰对应关系、实际几何可绘制性、渐变标识唯一性和不拦截点击检查。

## 验证结果

- 前端生产构建与 TypeScript 检查通过。
- 称号选择、个人排位资料、排行榜和对局身份相关单元测试 17 项通过、0 失败。
- 真实浏览器回归通过：1440×900、390×844、360×780 的称号中心纹饰、选择/切换/取消、44px 触控区域、无横向溢出和减少动态效果。
- 390×844、360×780 的旋转对局画布与称号显示检查通过。
- 已人工检查桌面和手机截图，背景围绕主徽章显示，称号文字与操作按钮可见。
