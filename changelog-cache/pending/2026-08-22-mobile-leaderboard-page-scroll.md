# 修复手机排行榜整页滑动范围

- 日期：2026-08-22
- 分类：修复
- 影响范围：大厅排行榜、排位榜、Leader 榜、手机竖屏
- 状态：已完成

## 玩家可见说明

- 手机竖屏下，排行榜从标题、模式页签、统计信息到榜单内容的整个区域都可以上下滑动，不再必须从榜单列表内部起滑。

## 技术说明

- 将窄屏排行榜的纵向滚动职责提升到整个排行榜页面，覆盖标题、页签、筛选、统计信息和榜单内容。
- 移除窄屏下排位榜与 Leader 榜的嵌套滚动拦截，仅在宽屏恢复榜单内部滚动，保持桌面端固定工具区的原有交互。
- 更新移动端排行榜滚动结构回归测试，锁定窄屏整页滚动与宽屏内部滚动的断点行为。

## 验证结果

- 排行榜及排位相关自动化测试通过：35 项全部通过。
- `npx next build` 生产构建和 TypeScript 检查通过。
- 实际浏览器在 `390×844` 下从标题区与页签区起滑，页面滚动位置分别从 `0` 变为 `620` 和 `480`。
- 实际浏览器在 `360×780` 下从标题区起滑，排位榜与 Leader 榜滚动位置分别从 `0` 变为 `560` 和 `500`；主要页签与筛选按钮触控高度均不小于 `44px`。
- 桌面 `1280×720` 回归验证通过：页面外层保持固定，榜单内部滚动位置从 `0` 变为 `450`。
