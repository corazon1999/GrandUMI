## 玩家可见说明

- 修复 OP14-090 在双方场上存在当前费用为 0 或 8 以上角色时未获得【速攻】的问题；费用被降低到负数的角色会按 0 费正确参与判定。

## 技术说明

- 为 OP14-090 补注册基于双方角色区当前费用的动态持续关键词，条件满足时赋予自身【速攻】，场况或费用变化后会实时重新判定。
- 保留原有登场时横置对方当前费用为 0 的角色效果，并统一使用最低为 0 的当前费用计算。
