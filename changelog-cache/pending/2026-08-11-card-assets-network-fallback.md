# 卡图与卡背弱网加载保护

- 日期：2026-08-11
- 分类：修复
- 影响范围：卡牌图鉴、卡背广场、自定义卡背、静态资源加载
- 状态：已完成

## 玩家可见说明

- 卡图或自定义卡背遇到线路无响应时会自动切换备用入口，不再无限空白等待；所有候选入口都失败时会显示明确占位。
- 卡背广场读取超过 8 秒会显示超时提示和重试按钮，玩家无需刷新整个网页。
- 卡牌数据和图片启用长期边缘缓存，已缓存资源的加载延迟显著降低。

## 技术说明

- 正式主域的本地图片增加 `direct.grand-umi.com` IPv4 直连候选，本地与测试环境不会跨环境回退。
- 图鉴缩略图增加 5 秒有界超时，自定义卡背增加 6 秒超时与一次直连重试，并以项目内置卡背作为最终兜底。
- Cloudflare 缓存规则新增 `/cards-webp/`、`/data/allCards.json` 和 `/card-back-images/`，边缘 TTL 为 30 天；静态资源沿用源站的一年浏览器缓存头。
- 源站持久启用 TCP MTU 探测，在路径 MTU 黑洞出现时自动收缩报文大小；未保留测试中无改善的固定 MSS 规则。
- Cloudflare Free 套餐不允许关闭 IPv6 Compatibility，因此保留 IPv6 配置并由应用层 IPv4 直连入口承担故障回退。

## 验证结果

- `node --test tests/*.test.mjs`：124 项全部通过。
- `tsc --noEmit`：通过。
- `npm run build`：生产构建通过。
- 公网 `allCards.json` 连续 3 次完整下载耗时 0.52～1.56 秒，均返回 1,397,473 字节。
- 公网抽测 20 张 OP05 缩略图全部成功，p95 1.104 秒，最大 1.107 秒；缓存状态由首次 `MISS` 转为 `HIT`。
