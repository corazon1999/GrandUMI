# 组卡列表改为卡面网格

- 日期：2026-08-13
- 分类：优化
- 影响范围：组卡界面、桌面端与手机竖屏
- 状态：已完成

## 玩家可见说明

- 组卡界面的当前卡组改为五列卡面网格，领航卡固定显示在首位，主卡数量直接覆盖在卡面底部，可以更直观、紧凑地浏览整副构筑。
- 保留轻点减少卡牌、长按查看详情和桌面悬停预览，并确保手机端导出与保存按钮拥有足够大的触控区域。

## 技术说明

- 将原横向卡牌条目替换为固定五列、5:7 比例的响应式卡面组件，数量与领航标识使用卡面底部覆盖角标。
- 桌面卡组侧栏扩展至 24rem；网格操作继续复用既有的增减卡、长按和悬停交互。
- 为网格结构、领航排序、数量角标、响应式侧栏和底部按钮触控尺寸补充回归断言。

## 验证结果

- 通过 18 项组卡界面、一图流和移动端相关 Node 回归测试。
- 通过 TypeScript 类型检查与 Next.js 生产构建。
- 使用实际浏览器验证桌面 1280×720、手机竖屏 390×844 和 360×780；均保持五列、无横向溢出，底部主要按钮为 44px 高且完整可见。
