# 一键观战保持目标玩家主视角

- 日期：2026-08-08
- 分类：修复
- 影响范围：在线玩家列表、一键观战、观战牌桌视角
- 状态：已完成

## 玩家可见说明

- 从在线玩家列表点击某位对战中玩家进行观战时，被点击的玩家现在会稳定显示在下方主视角，不再因其对局座位不同而显示成对手。

## 技术说明

- 在线玩家列表下发对战座位，一键观战请求携带目标座位，服务端按每位观战者保存对应的主视角。
- 观战广播按目标座位生成并分发脱敏快照；双方隐藏区仍保持不可见，且仅在存在反向视角观战者时额外生成对应快照。

## 验证结果

- 新增观战座位映射与隐藏区脱敏回归测试，2 项全部通过。
- 排除既有 OP17 专项后的服务端测试 440 项全部通过；前端 `npm run build` 生产构建通过。
- 完整服务端测试共 600 项，其中 594 项通过；6 项既有 OP17 卡数与印刷数值断言失败，与本次观战改动无关。
