# 新增全局游戏音效系统

- 日期：2026-08-08
- 分类：新增
- 影响范围：大厅、对战、观战、回放与全局设置
- 状态：已完成

## 玩家可见说明

- 新增出牌、攻击、格挡、反击、伤害、KO、回合切换、胜负结算、邀请、聊天和断线重连等游戏音效。
- 设置窗口新增音效开关、音量调节与试听功能，静音和音量设置会保存在当前浏览器中。
- 音效会遵守浏览器的首次交互播放限制，并在页面进入后台时停止，避免后台突然发声。

## 技术说明

- 使用单例 Web Audio 引擎统一管理素材预加载、并发上限、同类音效冷却、优先级抢占、音量和轻微音高变化。
- 根据真实对局快照、动作名称与全局网络事件触发语义化音效；重连快照、回放倒退和同 Tick 更新只重建基线，避免重复播放。
- 首版包含 21 个 Kenney CC0 Ogg 音效，并保存素材包、原始文件名与许可证映射；新增资源完整性、格式、单文件体积和总体积检查脚本。

## 验证结果

- `npm run check:audio`：通过，21 个 Ogg 文件均存在且格式有效，总大小 229784 字节。
- `node_modules/.bin/tsc --noEmit`：通过。
- `npm run build`：通过，Next.js 生产构建、类型检查与 9 个页面生成成功。
- 生产预览人工验证通过：设置窗口可打开，首次交互后试听正常，静音状态刷新后仍保留，控制台无音效加载错误。
