# 单机高可用与对局故障恢复

- 日期：2026-08-15
- 分类：优化
- 影响范围：正式服对局恢复、断线重连、发布与进程自愈
- 状态：已完成

## 玩家可见说明

- 服务器进程异常或版本切换后，进行中的 PvP 对局会通过房间恢复记录重建，玩家重新连接后可回到原座位。
- 重复发送的同一操作在服务恢复后仍会去重，降低网络抖动造成重复结算的风险。
- 正式服发布改为本机双槽切换；新版本异常时会恢复上一稳定槽位，构建任务也不会再抢占在线对局的主要资源。

## 技术说明

- 增加每 16 个已接受动作更新的私有恢复快照、状态哈希、持久化 `requestId`、服务端日志序号与损坏日志隔离。
- 正式数据目录启用单写者租约，A/B 后端共享数据时拒绝双进程写入。
- 增加 systemd A/B 服务、5 秒存活检查、三连败自愈、原槽重启、本机备用槽切换与失败回滚。
- 发布包按提交隔离，在独立 Git worktree 和低优先级 build slice 内构建；静态资源以硬链接复用未变化文件。
- 增加生产、构建资源 slice、只读检查与无房间切换演练脚本，以及完整运维说明书。
