# 在线玩家操作改为单行图标

- 日期：2026-08-25
- 分类：优化
- 影响范围：大厅在线玩家列表、手机竖屏布局
- 状态：已完成

## 玩家可见说明

- 在线玩家的姓名与添加好友、观战或邀请、举报操作现在保持在同一行，窄屏下不再拆成两排。
- 操作入口改为紧凑图标按钮，并从在线玩家列表移除了屏蔽入口；屏蔽管理仍可在好友中心进行。

## 技术说明

- 将玩家卡片改为单行弹性布局，玩家信息可收缩截断，操作区固定为三个 44×44px 图标触控按钮。
- 为观战按钮和玩家安全操作增加可复用的图标模式；在线玩家列表通过配置仅显示举报操作，不影响局内等其他位置的屏蔽与举报功能。
- 为所有图标按钮保留 `aria-label` 与提示文本，覆盖添加、接受或等待好友申请、邀请、观战和举报等状态。

## 验证结果

- `git diff --check`、`npx tsc --noEmit` 和 `npm run build` 通过。
- 在线玩家布局、好友申请、观战控制及相关安全操作共 20 项自动化测试通过。
- 在真实浏览器中以 390×844 和 360×780 两档手机竖屏检查：三枚按钮均为 44×44px，玩家信息与操作同排显示，无重叠、无越界，长昵称正常截断。
