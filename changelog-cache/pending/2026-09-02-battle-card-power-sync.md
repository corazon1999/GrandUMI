# 战斗中的卡面力量与结算同步

- 日期：2026-09-02
- 分类：修复
- 影响范围：海克斯模式、战斗卡面力量显示、观战与回放
- 状态：已完成

## 玩家可见说明

- 修复“一板一眼”等仅在本次战斗增加力量的效果已经显示在中央战斗面板，但攻击中的领航或角色卡面仍显示旧力量的问题。
- 阻挡发生后，本次战斗的防守力量会正确跟随阻挡角色显示，不再保留在原目标上。

## 技术说明

- 卡面继续以服务端快照中的领航/角色当前力量为基础，并仅对当前攻击者或有效防守目标叠加权威战斗临时加成，避免污染常驻力量状态或重复计算咚。
- 战斗参与者按卡牌实例 ID 判断，兼容双方视角、GM 强制攻击、观战、回放和阻挡替换；旧回放缺少临时加成字段时安全回退为 0。

## 验证结果

- 前端完整自动化测试：481 项全部通过。
- TypeScript 类型检查与 Next.js 生产构建通过。
- 真实浏览器验证：1280×720 桌面端显示攻击方 8000、防守方 5000；390×844 与 360×780 手机竖屏均自动旋转为横屏画布，双方卡面完整可见且力量同步，控制台无错误。
