# 布局设置入口常驻

- 日期：2026-08-08
- 分类：修复
- 影响范围：登录、大厅、好友房、游戏与回放的布局切换
- 状态：已完成

## 玩家可见说明

- 设置按钮现在会常驻在界面右上角，切换到手机竖屏后也能随时重新选择横屏或电脑布局。
- 游戏与回放的竖屏提示界面同样保留设置入口，切换为手机横屏后会立即恢复牌桌显示。

## 技术说明

- 将布局模式提升为应用级共享状态，并由全局入口统一打开布局设置弹窗；大厅原有设置入口继续复用同一状态。
- 游戏与回放路由接入布局预览画布，方向提示优先服从明确选择的手机横屏或手机竖屏模式。
- 为大厅顶栏和游戏菜单预留常驻按钮空间，避免窄屏下操作入口相互遮挡。

## 验证结果

- `npx tsc --noEmit --incremental false` 通过。
- `npm run build` 通过，Next.js 16.2.6 完成全部应用路由的生产构建。
- `git diff --check` 通过。
- 已在 428×916 本地浏览器视口验证手机竖屏大厅，常驻设置按钮可见且可切换为 844×390 手机横屏画布。
- 已使用真实本地回放验证：手机竖屏时方向提示覆盖牌桌但不遮挡设置入口，切换手机横屏后提示立即隐藏、回放牌桌与控制栏恢复显示；浏览器控制台无错误或警告。
