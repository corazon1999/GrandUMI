# 聊天语录独立赛季额度与固定贝里价格

- 日期：2026-09-03
- 分类：修复
- 影响范围：标准排位结算、聊天装饰交易所、既有钱包迁移、电脑端与手机竖屏、多语言
- 状态：已完成

## 玩家可见说明

- 所有在售聊天语录统一为 50,000,000 贝里；交易所只显示独立的本赛季语录额度和贝里价格，不再显示 RP 钱包或 RP 价格。
- 语录额度以本赛季标准排位历史最高悬赏金累计：首次读取会补齐已有峰值，之后只有刷新历史纪录时才增加差额；掉分后回到旧纪录不会重复增加，购买也不会改变当前悬赏金、段位或对局结算。
- 已拥有和已装配语录会稳定排在未拥有语录之前，购买成功后立即移动到已拥有分组；历史藏品仍保持永久所有权、装配和开场／胜利演出能力。
- 交易所相关余额、价格、规则、错误提示和购买状态已同步适配简体中文、英文与日文，并完成 390×844、360×780 两档手机竖屏验证。

## 技术说明

- 服务端以当前赛季 `highest_rank_points` 作为唯一铸币水位，账本保存已记账峰值；结算、首次读取和进程重启都只补发未记账的新峰值差额，狂野排位使用禁用交易所的独立数据库，不参与累计。
- 旧 `rank_exchange_wallets` 与操作流水在单个 SQLite `BEGIN IMMEDIATE` 事务内转换为安全整数莓果字段，并原样保留旧表作为受控回退副本；根据历史峰值、当前排位进度周期边界及成功购买流水重建余额，既纠正旧版掉分损失，也移除归零回升重复额度。迁移含逐账号审计，多实例初始化串行化，负数、溢出、未知或混合版本结构、孤儿钱包和孤儿成功购买流水均失败关闭并回滚。
- 购买请求携带固定价格握手值，但扣款始终使用服务端常量；条件更新、永久所有权与幂等操作流水在同一立即事务中提交，旧价格或缺失价格会在扣款前拒绝。前后端统一限制到 JavaScript 可精确表示的非负整数范围。
- 测试服指定账号额度校准已有独立的审计表与原子 SQL 操作流程；该流程只更新独立额度及防重复铸币水位，并记录调整前后值和排位观测值，不会更新排位资料。
