# 卡组广场详情采用一图流预览

- 日期：2026-08-10
- 分类：优化
- 影响范围：卡组广场、卡组详情、手机竖屏
- 状态：已完成

## 玩家可见说明

- 在卡组广场打开任意卡组详情后，会以一图流样式查看完整构筑，卡牌数量、卡号、主卡组与领航分区一目了然。
- 投稿中使用的异画会在详情预览中保持一致；点赞、复制到我的卡组等操作保持原有位置与功能。

## 技术说明

- 卡组广场详情复用既有一图流生成器，将投稿快照的领航、卡牌数量与异画映射转换为预览图片，并在关闭或切换详情时释放临时图片 URL。
- 预览按可用宽高等比缩放，适配详情弹窗的桌面端与手机竖屏布局；卡牌数据或图片生成异常时显示明确失败状态。

## 验证结果

- `npm run test:deck-plaza`：4 项测试全部通过。
- `npm run test:deck-image-export`：5 项测试全部通过。
- `npm run build`：Next.js 生产构建与 TypeScript 检查通过。
- 实际浏览器验证 `1920×947`、`390×844`、`360×780`：一图流预览及点赞、复制按钮均完整可见，手机竖屏无重叠。
