# 一图流预览完整适配可视区域

- 日期：2026-08-10
- 分类：优化
- 影响范围：卡组编辑器、一图流预览、桌面端与手机竖屏
- 状态：已完成

## 玩家可见说明

- 一图流预览会根据弹窗的可用宽度和高度等比缩放，在浏览器保持 100% 缩放时无需滚动即可查看完整图片。
- 手机竖屏下的关闭与下载按钮保持完整可见并提供足够的触控区域，页面设置按钮不再遮挡预览弹窗。

## 技术说明

- 预览图片改为在确定尺寸的相对定位容器中绝对居中，并同时应用最大宽高约束，避免图片固有高度撑开滚动区域。
- 一图流弹窗层级提高到全局设置入口之上；顶部关闭键和底部操作键的触控高度统一为至少 44px。
- 补充源码回归断言，覆盖宽高约束、弹窗层级和移动端触控尺寸。

## 验证结果

- `npm run test:deck-image-export`：5 项测试全部通过。
- `npm run build`：Next.js 生产构建与 TypeScript 检查通过。
- 实际浏览器验证 `1920×947`、`390×844`、`360×780`：`1440×2046` PNG 均完整显示，预览区域 `scrollHeight` 等于 `clientHeight`，无需滚动；两档手机尺寸下三个操作按钮均达到 44px 高。
