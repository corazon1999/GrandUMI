# QQ 群机器人工作器自动恢复

- 日期：2026-08-17
- 分类：优化
- 影响范围：QQ 群机器人聊天、Bug 反馈检查与管理员指令
- 状态：已完成

## 玩家可见说明

- QQ 群机器人的本地回复工作器意外停止或遇到电源状态变化后会自动恢复，避免消息长期无人响应。

## 技术说明

- 聊天与管理员工作器的计划任务新增每 5 分钟一次的存活兜底触发器，并保留登录触发与单实例限制。
- 两个任务允许在电池供电时启动和继续运行，避免 Windows 默认电源策略停止工作器后不再恢复。

## 验证结果

- `py -m unittest discover -s qq-bug-bot/tests -p "test_*.py" -v`：60 项测试全部通过。
- 两份 PowerShell 安装脚本均通过语法解析，计划任务参数验证为 5 分钟重复、允许电池启动且不会因切换电池而停止。
- 已重新安装并启动 `GrandUMI-Chat-Agent` 与 `GrandUMI-Admin-Agent`；两者均为 Running、各有 2 个触发器，重复间隔为 PT5M。
- 恢复后积压的 Bug 检查任务已成功处理并在 QQ 群回复 Bug #384。
