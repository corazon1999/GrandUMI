# 登录页补充非官方项目声明

- 日期：2026-08-14
- 分类：优化
- 影响范围：Web 登录页、界面多语言
- 状态：已完成

## 玩家可见说明

- 登录页现在会明确说明 GrandUMI 是未获得相关权利方授权、认可或赞助的非官方玩家项目，并标注相关名称、角色与卡牌素材的权利归属。

## 技术说明

- 在所有玩家进入项目前必经的登录面板中加入醒目的非官方项目声明，并使用独立的可访问名称标识声明区域。
- 为声明补齐简体中文、英文和日文文案，切换界面语言后同步显示对应声明。

## 验证结果

- `node --test tests/*.test.mjs`：169 项测试全部通过。
- `npm run build`：Next.js 生产构建与 TypeScript 检查通过。
- 实际浏览器检查：桌面 `1280×720`、手机竖屏 `390×844` 与 `360×780` 下声明、账号输入框和主要登录按钮均完整可见且无页面溢出；英文长文案在 `360×780` 下同样通过。
