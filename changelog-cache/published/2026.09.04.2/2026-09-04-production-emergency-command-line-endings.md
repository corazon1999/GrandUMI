# 正式服紧急发布远程命令换行兼容修复

- 日期：2026-09-04
- 分类：修复
- 影响范围：Windows 正式服紧急发布入口、Linux 版本化 A/B 发布启动
- 状态：已完成

## 玩家可见说明

- 修复正式服紧急更新在进入远端安全门禁前被命令换行格式阻止的问题，确保已验证版本可正常进入 A/B 发布流程。

## 技术说明

- Windows PowerShell here-string 会携带 CRLF；SSH 将其原样交给 Linux shell 后，`set -Eeuo pipefail` 被解析为无效的 `pipefail\r`。
- 远程命令载荷现在会在 SSH 执行前显式移除 CR，仅归一化传输层换行，不改写目标提交中的版本化服务器脚本或绕过任何发布门禁。
- 部署契约测试新增顺序约束，要求换行归一化发生在构造版本化命令之后、远程执行之前。

## 验证结果

- 部署证明与正式 A/B 发布链定向门禁测试 8/8 通过。
- `deploy-hk.ps1` 仍保持 UTF-8 BOM，兼容 Windows PowerShell 5.1。
- 首次失败发生在远程脚本首行、任何构建或服务切换前；正式服活动槽和已部署版本复核未发生变化。
