# 复数贴咚快捷选择

- 日期：2026-08-08
- 分类：优化
- 影响范围：对战牌桌、贴咚操作
- 状态：已完成

## 玩家可见说明

- 选中己方领袖或角色后，可在操作区直接选择要赋予的咚数量；贴三张等复数贴咚不再需要反复点击咚堆。
- 快捷数量会根据当前活跃咚动态显示，并支持一键赋予全部活跃咚；原有从咚堆选择目标的操作仍可继续使用。

## 技术说明

- 在场上卡牌上下文操作区增加目标优先的贴咚数量面板，领袖与角色分别复用现有协议目标格式，一次提交所选数量。
- 面板仅在己方主要阶段、非战斗状态、已选中合法目标且存在活跃咚时显示；舞台不会出现贴咚入口。

## 验证结果

- 在 `opcgpro-web` 目录运行 `npm run build`，Next.js 生产构建、TypeScript 检查及静态页面生成全部通过。
- 运行 `git diff --check`，改动未发现空白字符错误。
