# 游戏内反馈结构化证据链

- 日期：2026-08-31
- 分类：新增
- 影响范围：游戏内问题反馈、对局权威诊断、运营 Case 与兼容存档
- 状态：已完成

## 玩家可见说明

- 游戏内提交问题反馈时，会自动附带当前版本、房间与网络恢复等必要诊断信息，减少反复追问卡住、跳回合和操作被拒绝时的现场细节。
- 自动证据不会上传聊天、密码、令牌、账号、私有手牌或完整牌局快照。

## 技术说明

- 客户端只提交带“非权威”标记的版本/提交、连接代次与视口白名单；schema、数字点分版本、完整提交号、时间和端点均由服务端重新规范化，原始断线原因只转换为安全类别。服务端在房间单读者队列中采集版本/提交/规则集、房间、回合与日志序号、相对棋钟、连接代次/重连摘要、终局结果和最近 16 条动作结果。
- 动作证据不保存动作参数；对手的拒绝尝试、请求 ID 和拒绝原因不会暴露。动作拒绝原因会限长并脱敏卡号与 GUID，客户端旧 `clientInfo` 继续按白名单兼容。
- 反馈幂等键以服务端认证账号做域分离摘要，未登录时才回退连接会话；同账号重连仍复用原反馈，不同提交者使用同一客户端 requestId 也会生成不同 Case 和文件，原账号与原 requestId 均不持久化。
- 兼容文件的分桶和文件名只使用反馈 ID 的稳定摘要，并采用同目录刷盘与原子替换。外部回放 ID 在任何持久化前复用云回放安全规则校验；后续回放关联失败不影响已经成功保存的 Case。重复、并发、重启和部分失败可安全重试；权威采集超时或队列关闭时保存明确不可用状态，不并发读取可变牌局状态。

## 验证结果

- 服务端证据、提交者域分离、跨账号防碰撞、纯哈希路径、回放 ID 预验证、恶意字段注入、原子幂等存储、队列时序、重连摘要与恢复重放安全定向回归 36/36 通过；前端反馈与云回放相关回归 25/25、原批次前端定向回归 37/37 通过。
- 服务端完整测试 1743/1743、前端完整测试 444/444 通过；2 个仅依赖 Windows 符号链接能力的服务端用例按既有条件跳过。
- WebSocket 协议契约通过（入站 92、出站 90），TypeScript 检查、卡牌内容检查、严格卡效审计和 Next.js 生产构建通过。
