# “最多 N 张咚”数量选择修复

- 日期：2026-08-31
- 分类：修复
- 影响范围：OP13-001、OP13-027、OP14-022、OP14-031，结束阶段咚恢复
- 状态：已完成

## 玩家可见说明

- OP13-001、OP13-027、OP14-022 与 OP14-031 的“最多 N 张咚”效果现在可以自行选择 0 到上限数量，不再自动取满。

## 技术说明

- 新增服务端权威数量选择入口，只供显式“最多 N 张”路径调用；提示按当前可用咚生成 0..N，响应后重新校验，可用数量不足时不会部分结算。
- OP14-022 通过卡牌专属 DSL 标志启用选择；OP14-031 使用独立的可提示结束任务。其他固定数量 DSL 与旧 `RefreshOwnDon` 快照任务保持原语义。

## 验证结果

- 服务端定向回归覆盖选择 0、部分、最大、取消、响应期间状态变化、OP14-031 结束任务、旧任务兼容和强制数量效果不回归。
- 卡牌内容清单及严格卡效审计通过；统一验证 9/9 通过。
