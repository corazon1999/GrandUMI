# 缩小手机效果发动确认界面

- 日期：2026-08-11
- 分类：优化
- 影响范围：对局、手机竖屏、效果发动确认
- 状态：已完成

## 玩家可见说明

- 手机竖屏对局中的效果发动确认改为紧凑横向提示条，不再用大卡图和圆形按钮遮住大部分牌桌；确认、取消和收起操作仍保持清晰易点。

## 技术说明

- 效果确认条改用旋转对局容器的 `cqw/cqh` 尺寸与容器断点，不再按手机物理竖屏的 `vw/vh` 和视口断点误判布局。
- 移除效果确认分支中的卡图和持续旋转大按钮，以效果源卡号、卡名和可滚动说明保留结算上下文；三个操作按钮的触控尺寸均不小于 44px。
- 展开与收起状态均使用布局安全区变量，兼容手机刘海、圆角及手势区域。

## 验证结果

- `npm run test:effect-confirm`：4 项效果确认布局测试全部通过。
- `npm run test:game-layout`：5 项旋转画布布局测试全部通过。
- `npm run build`：Next.js 生产构建和 TypeScript 检查通过。
- 内置浏览器在 `390×844`、`360×780` 下确认竖屏媒体条件与 `cqw/cqh`、尺寸容器能力可用；本地账号要求设置密码，未向真实对局注入服务端 Prompt。
