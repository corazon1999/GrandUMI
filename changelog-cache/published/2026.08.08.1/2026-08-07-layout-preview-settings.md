# 主界面布局预览设置

- 日期：2026-08-07
- 分类：新增
- 影响范围：主页导航、手机端响应式布局与本地调试体验
- 状态：已完成

## 玩家可见说明

- 主界面左下角新增“设置”入口，可在电脑、手机横屏和手机竖屏三种布局之间快速切换。
- 手机预览会使用固定尺寸画布并在窗口空间不足时自动等比缩小；手机“我的”页面也保留设置入口，方便随时切回电脑布局。

## 技术说明

- 新增 844×390 横屏与 390×844 竖屏虚拟画布，布局选择保存在浏览器本地，不上传服务器。
- 主页响应式规则改为基于预览画布尺寸的容器查询，弹窗、聊天、卡组、图鉴、排行榜等内容会随虚拟设备宽度真实切换，不会创建 iframe、重复登录或额外 WebSocket 连接。
- 从手机“我的”页面切回电脑布局时自动返回大厅，避免停留在桌面导航无法再次进入的手机专属页面。

## 验证结果

- `npx tsc --noEmit --incremental false` 通过。
- `npx next build` 通过，全部应用路由完成生产构建。
- `git diff --check -- opcgpro-web/src` 通过。
- 已在本地浏览器核对 1280×720 电脑画布、844×390 手机横屏、390×844 手机竖屏，以及手机“我的”页面的设置返回入口；三种模式的画布尺寸、导航显隐和弹窗定位均符合预期。
