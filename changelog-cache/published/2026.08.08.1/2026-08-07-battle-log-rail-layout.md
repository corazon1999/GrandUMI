# 调整对战页左右栏信息布局

- 日期：2026-08-07
- 分类：优化
- 影响范围：前端对战页、观战页与回放页的牌桌侧栏
- 状态：已完成

## 玩家可见说明

- 左侧不再显示无功能的“选中卡”和“记录”空栏目，改为集中展示可滚动的对战日志。
- 右侧不再重复展示日志，保留玩家信息与对局操作，并将“反馈 Bug 和建议”入口移到右侧底部。

## 技术说明

- `GameBoard` 的左侧栏直接复用现有 `GameLog`，继续使用日志自动滚动与分类样式。
- 右侧栏移除重复的日志实例，将操作区和反馈入口组合为底部区域；观战与回放模式继续按原有权限隐藏操作或反馈入口。

## 验证结果

- `npx tsc --noEmit` 通过。
- `npm run build` 通过，Next.js 生产构建、类型检查与全部页面生成成功。
- 生产预览服务可正常启动；无现成对局状态时 `/game` 按既有守卫返回大厅，未创建额外测试对局。
