# 卡图 WebP 分级加载优化

- 日期：2026-08-08
- 分类：优化
- 影响范围：对战卡牌、卡组编辑器、卡牌图鉴、领袖头像、开局浮层与卡牌详情
- 状态：已完成

## 玩家可见说明

- 首次进入对局或打开卡牌列表时，小尺寸卡图会优先加载轻量 WebP，明显减少等待和空白卡框。
- 悬停、右键和详情大图会按需加载高质量 WebP，在降低流量的同时保持卡面文字清晰。
- 卡背、领袖头像和“无法攻击”图标也改用轻量资源；派生图缺失时仍会自动回退原图，不影响正常显示。

## 技术说明

- 为 4803 张本地卡图生成 128px 缩略图与最大 960px 高质量 WebP，并补齐原先未覆盖的 196 张 JPG 卡图。
- 新增统一的小图、大图和原图回退路径，将对战、编辑器、图鉴、排行榜、卡组列表及开场浮层的本地卡图请求切换到对应 WebP 档位。
- 将全卡数据包延迟到首屏卡集与卡图开始显示后再后台加载，避免首次进入对局时争抢网络带宽。
- 为 WebP 卡图、旧版 WebP 卡背和状态图标补充一年 immutable 缓存头；保留 PNG/JPG 源文件作为生成源与兼容回退。

## 验证结果

- `npm run gen:card-thumbs` 成功：4803 张高质量 WebP、196 张新增 JPG 缩略图、状态图标全部生成，失败 0。
- `npm run build` 成功，Next.js 生产构建、TypeScript 检查和静态页面生成全部通过。
- 本地浏览器硬加载卡组编辑器时，首屏 87 张卡全部请求 `/cards-thumb/*.webp`，原始卡图请求 0、破图 0；悬停后正确按需请求 `/cards-webp/*.webp`，控制台无错误或警告。
- 抽查普通 PNG、高分辨率 PNG、JPG 和透明状态图标，卡面文字、透明区域与色彩显示正常；四类 WebP 响应均为 HTTP 200、`image/webp` 且带长期 immutable 缓存。
