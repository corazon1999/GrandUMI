# 贴咚改为操作前确认

- 日期：2026-08-18
- 分类：优化
- 影响范围：对局页贴咚操作、桌面端与手机竖屏旋转布局
- 状态：已完成

## 玩家可见说明

- 贴咚不再等待数秒后才生效；选择数量或目标后会先显示“确认贴 x 咚？”弹窗，确认后立即执行，取消则不进行贴咚。

## 技术说明

- 移除贴咚的 4 秒待提交与撤回队列，统一所有贴咚入口使用同一确认弹窗。
- 确认时立即发送贴咚请求并应用可回滚的即时视觉反馈；取消时不修改牌桌状态。
- 弹窗适配安全区、键盘 Escape 取消及中英文、日文动态文案，旋转缩放后的按钮触控区域仍不小于 44×44px。

## 验证结果

- `npx tsc --noEmit` 通过。
- `node --test tests/feedback-ui-actions.test.mjs tests/suggestion-list-ui.test.mjs tests/i18n.test.mjs`：16 项通过。
- `npm run build` 通过。
- 浏览器实测桌面端、390×844 与 360×780 手机竖屏旋转布局；弹窗完整可见，确认/取消按钮未与常驻控件重叠，最小触控边约 44.3px。
