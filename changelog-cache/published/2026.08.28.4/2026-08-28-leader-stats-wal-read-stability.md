# 跨环境 Leader 统计只读稳定性修复

- 日期：2026-08-28
- 分类：修复
- 影响范围：正式服 Leader 统计存储、测试服管理面板每日场次统计、正式服 A/B 切换
- 状态：已完成

## 玩家可见说明

- 修复测试服管理面板在正式统计库空闲、进程重启或正式服切槽后可能无法读取每日场次统计的问题，统计展示现在会随正式服务生命周期保持稳定可用。

## 技术说明

- 正式服作为 `leader-stats.db` 唯一写者，在写入路径与榜单读取路径一致时保留进程寿命 WAL 锚点连接，确保 `-wal` 与 `-shm` 侧车不会因最后一个连接退出而被删除。
- 测试服继续以 `ReadOnlyPaths=/data/grandumi` 只读挂载正式数据，绝不通过放宽目录写权限绕过 SQLite 侧车生命周期约束。
- 锚点建立失败时正式后端启动失败闭锁；正常关闭通过同一并发锁幂等释放连接，A/B 单写切换窗口由旧槽停止、新槽启动和 `/ready` 门禁收束。

## 验证结果

- `LeaderStatsStoreTests` 与 `AdminOperationsMetricsCacheTests` 定向测试 20/20 通过，覆盖锚点升级、外部只读、重复并发释放和释放后拒绝访问。
- 测试服迁移与只读边界定向测试 3/3 通过。
- 服务端完整测试 1552/1552 通过；前端 113 个测试文件共 412/412 通过。
- `npx tsc --noEmit` 与 `npm run build` 均通过。
