# 休息咚改为横置布局

- 日期：2026-08-10
- 分类：优化
- 影响范围：对局牌桌费用区
- 状态：已完成

## 玩家可见说明

- 费用区中的休息状态咚现在会横置 90 度显示，与竖直的活跃咚更容易区分。

## 技术说明

- 为休息状态的咚卡和数量槽交换宽高，并将卡面文字旋转 90 度；活跃咚与咚卡堆继续沿用原有竖版尺寸和交互。

## 验证结果

- 通过 `node --test tests/don-rest-orientation.test.mjs`。
- 通过 `tsc --noEmit`。
- 通过 `pnpm run build`（Next.js 生产构建）。
- 本地实际渲染确认小尺寸休息咚为 100.8 × 72 px，卡面正确横置且无裁切或溢出。
