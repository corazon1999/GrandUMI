# Windows 一键实时导出游戏 QQ 白名单

- 日期：2026-08-27
- 分类：新增
- 影响范围：游戏 QQ 白名单导入、QQ 群运维工具
- 状态：已完成

## 玩家可见说明

- 管理员现在可以在 Windows 上一键导出 GrandUMI 测试群的最新游戏白名单，减少旧名单、漏人或错误群数据被导入的风险。

## 技术说明

- 新增仓库根目录双击入口、PowerShell 编排脚本、容器内 OneBot 实时采样器及本地 Node 校验器；目标固定为 `GrandUMI测试群（297542853）`。
- 每次采样严格按群信息、成员列表、群信息三段 `no_cache=true` 调用，并要求群身份和三段人数完全一致；空名单、重复或无效 QQ、串群数据及不稳定快照均拒绝交付。
- 本地中转固定使用 `E:\GrandUMI-Temp`，远端脚本通过 SSH 标准输入执行而不落临时文件；最终 JSON 使用游戏实际的 `qqWhitelist.mjs` 解析逻辑前后两次校验并核对 SHA-256，不覆盖旧导出。
- 时间戳导出文件使用精确的 Git 忽略规则，不会污染工作区或阻断后续测试服部署。

## 验证结果

- `py -m unittest qq-bug-bot.tests.test_live_qq_whitelist_export -v`：15 项通过，覆盖一键入口、E 盘规则、三段无缓存调用、稳定性重试、群身份、空值、重复、无效 QQ、串群、并发文件归属、失败无伪输出、远端无临时落盘、同解析器复验、SHA-256 与导出文件忽略规则。
- `py -m unittest discover -s qq-bug-bot/tests -p 'test_*.py'`：机器人当前完整测试集 133 项全部通过。
- Windows PowerShell 5.1 语法解析通过；使用默认 SSH 目标完成端到端实时导出，最终复验文件接受 1573 名成员，并由游戏解析器与 PowerShell SHA-256 复核一致。
