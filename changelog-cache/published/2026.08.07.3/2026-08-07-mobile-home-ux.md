# 移动端登录与大厅交互优化

- 日期：2026-08-07
- 分类：优化
- 影响范围：移动端登录、大厅导航、匹配、好友房、聊天、卡组、图鉴、排行榜与个人中心
- 状态：已完成

## 玩家可见说明

- 手机竖屏现在可以正常完成登录和使用大厅，不再进入网页就被要求横屏。
- 大厅新增适合触屏的顶部状态栏和底部导航，匹配、好友房与单人测试的操作更集中清晰。
- 聊天、在线玩家、卡牌详情和确认操作在手机上改为更易操作的底部面板，并全面放大按钮、输入框和文字。
- 卡组、图鉴、排行榜、对局记录及友谊战房间完成窄屏适配，减少横向滚动和按钮拥挤。
- 实际牌桌与回放仍会在手机竖屏时提示旋转设备，返回大厅后可继续竖屏使用。

## 技术说明

- 移除根布局中的全局竖屏遮罩，将方向提示收敛到牌桌与回放页面，并恢复浏览器缩放能力。
- 首页改为小于 `lg` 断点使用移动端顶栏、五栏底部导航和独立个人中心，大屏继续沿用侧栏与常驻聊天布局。
- 大厅重构为匹配、好友房、单人三种互斥任务流；通用弹窗增加移动端底部抽屉、焦点约束、Esc 关闭和背景滚动锁定。
- 排行榜在移动端使用统计卡片，图鉴使用折叠筛选，卡组列表与历史记录补齐键盘语义和触控尺寸。

## 验证结果

- 在 `opcgpro-web` 执行 `npm run build`，Next.js 生产构建、TypeScript 检查和 9 个页面生成全部通过。
- 使用本地浏览器验证 320×568、390×844、667×375 和 1280×800 视口；页面宽度均与视口一致，无页面级横向溢出。
- 验证移动端登录、大厅三模式、聊天抽屉、个人中心、卡组、图鉴、卡牌详情和排行榜；320px 大厅与聊天抽屉的可见操作目标均不小于 44px。
- 浏览器控制台未发现错误或警告，桌面侧栏与常驻聊天布局回归正常。
