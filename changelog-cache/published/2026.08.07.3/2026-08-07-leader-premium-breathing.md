# 首异画领袖高级呼吸效果增强

- 日期：2026-08-07
- 分类：优化
- 影响范围：牌桌领袖卡视觉效果（OP17-039 蓝色洛克斯首异画）
- 状态：已完成

## 玩家可见说明

- 蓝色洛克斯首异画现在拥有更清晰的立体呼吸：人物会从背景中轻微浮起，并伴随双眼高光、上升能量、扫光和边框脉冲。
- 卡框、力量值、技能文字和名称栏保持静止；领袖横置后会停止彩色动态效果，避免干扰战斗信息。

## 技术说明

- 将原有单层轻微缩放改为静态卡图、反向景深背景、柔边人物主体、双眼辉光、扫光、粒子弧光和框内能量七层结构。
- 为每张异画增加主体遮罩、呼吸位移、缩放强度与独立能量周期配置，便于后续扩展其他领袖首异画。
- 洛克斯主体峰值缩放由 1.018 提升至 1.07，并增加最多 3px 上浮；主呼吸与能量动画使用不同周期，减少机械循环感。
- 保留横置状态和 `prefers-reduced-motion` 的静态降级处理。

## 验证结果

- `npm exec tsc -- --noEmit --incremental false`：通过。
- `npm run build`：通过，Next.js 生产构建与全部 9 个页面生成成功。
- `git diff --check`：通过，无空白错误。
- 内置浏览器受本机 `localhost` 访问隔离限制，未能执行实际牌桌截图对比；需在测试服发布后补充实机观感确认。
