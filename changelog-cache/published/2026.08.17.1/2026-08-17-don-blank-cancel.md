# 点击空白取消咚选择

- 日期：2026-08-17
- 分类：优化
- 影响范围：对局内咚选择与依附操作
- 状态：已完成

## 玩家可见说明

- 选择活跃咚准备依附时，点击牌桌空白处即可取消本次选择，误触后不必继续操作。
- 点击领航、角色、按钮等可操作区域时仍会执行原本的操作，不会被误判为取消。

## 技术说明

- 在牌桌画布层监听空白区域点击，并在存在待依附咚时清除本地选择状态。
- 为可点击卡牌增加交互目标标记，配合原生按钮、链接和表单控件的识别，避免事件冒泡导致误取消。

## 验证结果

- `node --test tests/don-selection-blank-cancel.test.mjs` 通过。
- `npx tsc --noEmit` 与 `npm run build` 通过。
- 本地真实单人对局验证通过：桌面端点击空白可取消，点击领航仍能正常依附。
- `390×844` 与 `360×780` 手机竖屏实际浏览器验证通过，空白取消后咚恢复为未选择状态。
