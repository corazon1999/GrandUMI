# 拆分局内聊天与好友中心

- 日期：2026-08-17
- 分类：优化
- 影响范围：对局页聊天、好友中心、手机竖屏布局
- 状态：已完成

## 玩家可见说明

- 对局页原聊天气泡现在仅显示局内聊天，不再混入好友私聊。
- 对局页新增独立好友按钮，可直接打开与主页一致的好友中心，查看好友消息、申请和添加好友。
- 局内消息与好友消息分别显示未读提醒，避免两类消息相互干扰。

## 技术说明

- 从 `GameChatPanel` 移除好友会话选择、私聊消息流和私聊发送逻辑，保留局内消息、快捷语和局内未读计数。
- 对局页通过独立入口复用完整 `FriendsPanel`，好友消息与好友申请合并显示提醒数量，并继续支持离线留言。
- 新增回归断言，防止好友私聊再次嵌入局内聊天面板。

## 验证结果

- `node --test tests/friend-chat-tabs.test.mjs tests/spectator-controls.test.mjs`：12 项全部通过。
- `npm run build`：Next.js 生产构建及 TypeScript 检查通过。
- 浏览器实际对局验证通过：电脑布局、390×844 与 360×780 手机竖屏自动旋转布局均可分别打开局内聊天和完整好友中心，且主要按钮可见可操作。
