# 手机端对局设置布局适配

- 日期：2026-08-17
- 分类：修复
- 影响范围：手机竖屏自动旋转后的对局与回放设置弹窗
- 玩家可见说明：手机进入对局或回放后，设置弹窗会充分利用横屏空间，以紧凑双栏展示各项设置；卡牌大小选项保持单行排列，减少滚动和内容裁切。
- 技术说明：设置弹窗根据对局画布的四分之一旋转上下文切换为宽版双栏布局，并将卡牌显示选项从视口媒体查询改为画布容器查询，避免竖屏浏览器视口导致旋转后的横屏布局误用窄屏样式。
- 验证结果：23 项布局与对局交互回归测试通过，Next.js 生产构建通过；实际浏览器在 390×844 与 360×780 两档竖屏中均确认旋转后的双栏布局、滚动区域和关闭入口可用，最小按钮触控尺寸分别约为 46px 与 44.3px，桌面端仍保持原有单栏弹窗。
