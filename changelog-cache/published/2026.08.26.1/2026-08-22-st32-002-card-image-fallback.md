# 修复 ST32-002 御殿卡图加载失败

- 日期：2026-08-22
- 分类：修复
- 影响范围：卡牌图鉴、组卡器、对局卡牌与卡图预览
- 状态：已完成

## 玩家可见说明

- 修复 ST32-002 光月御殿在部分卡图资源缺失时无法显示的问题。
- 高清图暂不可用时会先显示同画面的缩略图；异画资源也缺失时会回退同卡默认画面，不再直接显示空白或文字占位。

## 技术说明

- 卡图加载回退链新增高清图到缩略图、异画到同卡默认画面的降级路径，并保留原图、外部图与卡背兜底。
- 派生卡图即使已有内容哈希查询参数，也会追加独立恢复修订号，绕过浏览器和 CDN 已缓存的旧 404。
- 线上诊断确认 ST32-002 默认高清图、异画缩略图/高清图及原始 PNG 缺失，而默认缩略图仍可访问；新回退链可直接利用现有资源显示卡面。

## 验证结果

- `npm run check:card-images`：4872 张原图及清单引用的 4687 张卡图，其缩略图和高清展示图均完整、最新且可解码。
- 相关 Node 回归测试：28 项通过。
- `npm exec tsc -- --noEmit`：通过。
- `npm run build`：Next.js 生产构建通过。
- 本地组卡器实测 ST32-002 默认画与异画的缩略图、高清预览均加载成功；`390×844`、`360×780` 两档竖屏下卡图完整可见且页面无横向溢出。
