# 优化同名目标的选中标识

- 日期：2026-08-26
- 分类：优化
- 影响范围：效果、事件反击及其他卡牌目标选择面板
- 状态：已完成

## 玩家可见说明

- 选择效果或反击事件的目标后，目标卡牌会显示醒目的“✓ 已选”徽标；双方场上存在多张同名卡时，仍可结合“己方/对方”和场上第几位准确确认目标。

## 技术说明

- 选择面板继续以服务端下发的卡牌实例 ID 维护选中态与提交值，并为每个候选暴露实例级标识和 `aria-pressed` 状态。
- 服务端仍以 `promptId`、选择数量、去重和合法候选实例 ID 为权威校验边界；本次仅补足普通目标此前只有黄框与缩放、缺少显式图标的 UI 缺口。
- QQ 反馈 Q455 为主记录，Q475 是同一问题的后续重复记录。

## 验证结果

- 后端真实同卡号双实例 Prompt 回归 1/1 通过：两个候选卡号相同但实例 ID 不同，选择第二张后端到端返回第二张的唯一 ID。
- 前端选中标识、实例 ID、阵营/位置和安全区约束测试 3/3 通过；TypeScript `npx tsc --noEmit` 通过。
- 浏览器实测 `390×844` 与 `360×780` 手机竖屏：均自动旋转为横屏画布，“✓ 已选”清晰可见，目标、确认按钮与常驻控件无重叠，无页面横纵溢出；缩放后的确认按钮短边分别为 48px、44.31px，目标触控区短边分别为 96px、88.62px。
