# 平局申请附带 Bug 描述

- 日期：2026-08-25
- 分类：优化
- 影响范围：真人对局、协商平局、断线重连、服务重启恢复、桌面与手机竖屏界面
- 状态：已完成

## 玩家可见说明

- 发起“出 Bug 了，请求平局”时现在必须填写本局发生了什么 Bug；收到申请的玩家会在同意或拒绝前清楚看到对方填写的描述。
- 刷新、断线重连或服务恢复期间，尚未回应的平局申请及其描述会保持一致；申请被拒绝、同意或因其他方式结束后，旧描述不会残留到下一次申请。

## 技术说明

- 服务端将申请者与去除首尾空白后的描述作为成对权威状态，独立校验必填、文字类型和 500 字上限；无效请求不会广播、持久化或改变对局状态。
- 描述进入参战玩家状态快照和私有恢复校验快照，但不会通过观战快照泄露；所有终局入口统一清理待回应申请。
- 已接受动作日志保留描述并通过确定性重放恢复。为兼容功能上线前没有描述字段的旧动作日志，只有重放入口会注入明确的旧版本占位说明，实时请求仍执行严格校验。
- 客户端表单提供字符计数、必填与长度反馈；回应弹窗使用受限高度的描述滚动区，避免长文本遮挡同意和拒绝按钮。
