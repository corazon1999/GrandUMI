# 开局倒计时不再受设备时间偏差影响

- 日期：2026-08-18
- 分类：修复
- 影响范围：投骰选择先后手、调度起始手牌、重新同步
- 状态：已完成

## 玩家可见说明

- 修复玩家设备时间不准确时，先后手或调度倒计时会提前归零、按钮无法操作且重新同步无效的问题。
- 倒计时到零后、服务器完成自动选择前，玩家仍可提交先后手或调度选择，不再被客户端提前锁死。

## 技术说明

- 对局状态快照新增生成时的服务端 UTC 时间，客户端以该时间为锚点并使用浏览器单调时钟推进倒计时，不再依赖玩家设备的墙上时钟。
- 先后手与调度操作取消仅由客户端倒计时归零触发的提交拦截，最终截止和动作顺序继续由服务端权威处理。
- 保留对旧服务端快照的兼容回退，并补充服务端快照时间字段与增量快照等价性验证。

## 验证结果

- 前端倒计时、先后手与调度定向测试：8 项通过，失败 0 项，覆盖设备时间快慢 20 分钟与旧快照兼容。
- `npx tsc --noEmit`：通过。
- `npx next build`：Next.js 生产构建通过。
- 服务端完整测试：1153 项通过，失败 0 项。
- 390×844、360×780 浏览器尺寸检查：页面无横向溢出，按钮触控高度保持不小于 44px。
- 前端完整测试：与本修复相关用例全部通过；工作区内其他并行改动仍有 3 项既有失败（平局结算、反馈入口、排位快照），未纳入本修复。
