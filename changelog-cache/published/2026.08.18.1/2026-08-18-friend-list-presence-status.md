# 好友列表常驻显示在线状态

- 日期：2026-08-18
- 分类：优化
- 影响范围：好友中心、好友聊天会话列表
- 状态：已完成

## 玩家可见说明

- 好友列表现在会在每位好友旁直接显示在线、匹配中、对战中、观战中或离线状态，无需先点开好友；最近聊天消息仍会同时保留。

## 技术说明

- 好友会话列表直接使用好友列表协议已有的在线状态，在最近消息行前增加常驻、带颜色区分的状态标签，并同步完善无障碍描述。
- 状态标签使用固定宽度策略，最近消息在空间不足时截断，避免窄屏下状态被挤出列表项。

## 验证结果

- 通过 `node --test tests/friend-chat-tabs.test.mjs tests/friends-spectate.test.mjs`，共 11 项测试。
- 通过 `npm run build`，包含生产构建和 TypeScript 检查。
- 使用实际浏览器检查 900×720 桌面端、390×844 和 360×780 手机竖屏：五种状态均可见，长昵称与长消息不会遮挡状态，无横向溢出，列表项高度保持 72px。
