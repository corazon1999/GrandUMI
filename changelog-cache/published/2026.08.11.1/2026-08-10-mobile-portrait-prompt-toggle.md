# 修复手机竖屏选择面板按钮越界

- 日期：2026-08-10
- 分类：修复
- 影响范围：对局内卡牌选择面板、手机竖屏自动旋转布局
- 状态：已完成

## 玩家可见说明

- 修复手机竖屏对局中选择面板的“隐藏”和“恢复”按钮可能超出屏幕或被安全区裁切的问题，按钮现在会避让屏幕边缘并更易点击。

## 技术说明

- 选择面板的隐藏与恢复按钮共用一套定位样式，接入旋转布局映射后的左右、底部安全区变量，并保留聊天与观战控件的避让距离。
- 按钮使用更大的触控区域，确保画布在较窄竖屏设备上缩放后仍具有足够的可点击范围。
- 在项目协作规范中新增移动端竖屏 UI 适配要求，后续新增或调整的 UI 必须同步验证常见竖屏尺寸、安全区及对局自动旋转场景。

## 验证结果

- `npm run test:effect-confirm`：4 项测试全部通过，包含隐藏/恢复按钮安全区回归测试。
- `npm run test:game-layout`：5 项测试全部通过，包含 390×844、360×780 竖屏旋转布局计算验证。
- `npm run build`：Next.js 生产构建、TypeScript 检查及静态页面生成全部通过。
