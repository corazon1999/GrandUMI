- 影响范围：正式服 A/B 发布、旧对局恢复、QQ 双群白名单同步接口

## 玩家可见说明

- 完善 QQ 双群白名单更新的正式发布兼容检查；更新过程可继续保留旧对局恢复，同时任何未审计的接口、卡牌或对局状态变化都会被拒绝。

## 技术说明

- 逐段审计 QQ 白名单内部 HTTP 端点从单群 v1 到双群 v2 的唯一历史变更，确认其只处理固定双群配置、协议分流、请求与响应校验，不被卡牌规则、房间状态、动作日志或快照重放引用。
- 为该端点增加独立的旧、新 Git blob 精确配对；只有受审计内容组合可通过，文件缺失、旧内容不符、目标内容被追加或今后再次修改均失败关闭，不放宽文件或目录。
- 再次确认共享账号数据库路径解析、`prepared` / `active` 权威激活、schema 与旧对局恢复消费者在这次功能变更中均未改变。

## 验证结果

- 生产分类函数行为测试覆盖 QQ 持久化与 QQ HTTP 端点两个精确正例，以及两者各自任意追加内容的失败关闭负例；卡牌数据、卡牌效果与对局状态负例继续被拒绝。
- 正式服旧版本到目标版本的全路径预演准确发现尚未分类的 HTTP 端点，且在修复前未启动正式发布或切流。
