# 反馈机器人容器权限配置

- 日期：2026-08-07
- 分类：优化
- 影响范围：QQ Bug 反馈机器人容器部署与数据持久化
- 状态：已完成

## 玩家可见说明

- 优化反馈机器人服务的容器权限与数据目录配置，减少部署后因权限问题无法读取配置或保存反馈的情况。

## 技术说明

- Dockerfile 先创建 GID 10001 的 `bugbot` 用户组，再让 UID 10001 的运行用户显式加入该组，避免用户与数据目录组不一致。
- 部署文档将服务器配置设为 `root:10001`、权限 `640`，并将数据目录归属设置为 `10001:10001`。

## 验证结果

- 已静态核对 Dockerfile 中用户组、运行用户与 `/data` 目录的 UID/GID 一致性。
- 已核对 README 中配置文件只允许 root 写入、容器用户组读取，数据目录允许容器用户持久化写入。
- 当前开发机未安装 Docker，未执行本地镜像构建或 Compose 实机验证。
