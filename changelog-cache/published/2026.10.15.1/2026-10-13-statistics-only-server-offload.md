# 历史对局离线归档与服务器空间回收

- 日期：2026-10-13
- 分类：优化
- 影响范围：GrandUMI 正式服与测试服存储、服务器历史日志、同机 Legion12 历史对局库
- 状态：已完成

## 玩家可见说明

- 将旧对局详情和历史云回放转为离线备份，保留账号、排位、比赛结果和卡牌统计；当前对局及近期回放继续保留。
- 腾出服务器磁盘空间，降低空间不足导致登录和持久化失败的风险。

## 技术说明

- 按用户本次授权，将历史发布快照、普通对局日志、日志压缩包、旧云回放、已结束且隔离失败的回放材料、已轮换系统日志及 Legion12 旧运行备份，归档到 `Z:\NoBackup\Corazon-Backup\GrandUMI-服务器清理备份-20261013-103246`。
- 十卷归档包含 171,120 个常规文件或链接，源内容合计 58,965,589,725 字节，压缩包合计 19,677,719,922 字节；每卷均校验服务器压缩流与 Z 盘 SHA-256，并逐文件核对内容、大小、权限及属主。通过验证后才清理服务器副本。
- 累计确认 128,921 份已备份旧云回放文件及其在线索引已撤除；在线业务在读取前按原有保留策略自然清理的 370 个文件没有进入本次删除清单。清理支持断点幂等重试，累计移除结果另存审计。
- 创建并校验 15 份统计与账号库 SQLite 一致性备份。保留活动房间恢复材料、当前 UTC 日期的日志、近期云回放及最近两份正式发布和 Legion12 运行备份。
- Legion12 历史库当前未被进程使用；完整原库备份及 SQLite 恢复验证通过后，删除 24,178 条关联历史事件并压实，由 18,396,090,368 字节缩减至 22,638,592 字节。全部比赛、参与者、卡组、卡牌统计、结算和恢复表的内容哈希保持一致，另有七条未关联事件保留。
- 两份服务器部署仓库各有 616 份受 Git 跟踪的遗留对局日志，已通过稀疏检出排除 `服务端WebSocket/MatchLogs/`，避免后续重新检出恢复旧日志；HEAD 和其他代码差异哈希均保持不变。
- 验收时根盘可用约 28.20GiB（36.46%），数据盘约 31.99GiB（80.02%），均超过本次至少 30% 的目标。

## 验证结果

- 十卷压缩流双端 SHA-256、完整 gzip/tar 遍历及逐文件内容和属性校验全部通过。
- Z 盘完整 Legion12 数据库解压到 E 盘后，SHA-256、SQLite 完整性及所有表行数校验通过；临时数据库已清理。压实后 255 场比赛、510 条参与者记录、13,586 条卡牌统计，以及结算、恢复与隔离表的行数和内容哈希均保持一致。
- 八个主要统计和账号保护库的只读 SQLite `quick_check` 通过，原有表均存在。当前云回放索引通过 SQLite、外键及引用文件检查，旧回放索引剩余零。
- 四个正式服和测试服前后端进程保持原进程号及 active 状态。`ygo.grand-umi.com` 与测试服外网就绪接口均返回 HTTP 200、`status=ready`、`storage.healthy=true`。
- 两条正式服 WebSocket 线路均通过真实握手与心跳往返验证，已结束的隔离回放失败材料计数降为零。
- 归档删除门禁四项隔离测试通过，覆盖完整备份、哈希错误、成员损坏及越界路径。稀疏检出隔离验证确认既有代码改动保留、重新检出仍排除旧日志。
- 完整清单、校验和、累计清理审计及验收报告保存在备份目录的 `README.md`、`SHA256SUMS.txt`、`SUMMARY.json` 和 `Metadata/` 下。
